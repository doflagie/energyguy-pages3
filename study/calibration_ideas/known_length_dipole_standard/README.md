## What You Will Be Able to Do

**TLO-1:** Given the required equipment — deploy and use the KNOWN-LENGTH DIPOLE STANDARD to verify or calibrate test instruments per TM-CAL-016, achieving the traceability and accuracy stated in Chapter 7, with a completed calibration log entry.

**TLO-2:** Given measured and reference values — compute the calibration error in Hz and ppm (or appropriate units) and determine pass/fail against the stated criterion.

---

## Scope

This manual covers use of a physically measured half-wave dipole antenna as a frequency standard and antenna analyzer calibration reference. At resonance, the dipole exhibits a known impedance (~70 Ω)

## How to Use This Course

1. Work units in order.
2. For each unit: **read the assigned TM chapter first**, then read the unit, then answer the self-check questions.
3. Self-check answers are at the bottom of each unit — try before looking.
4. The checkpoint at the end of each unit is a go/no-go.
5. Complete the Unit 5 lab before taking the final assessment.
6. Passing score: 13/15 (87%). All calculation questions must be correct regardless of total score.
