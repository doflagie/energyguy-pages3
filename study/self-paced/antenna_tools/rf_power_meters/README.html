Self-Paced Course — RF POWER METERS — TYPES AND OPERATION

TM-TOOL-008 — Open Handout TM-TOOL-008 Estimated time: 2–3 hours (reading + practice + lab) Handout: TM-TOOL-008 (rf_power_meters/tm.html) — keep it open throughout

What You Will Be Able to Do

TLO-1: Given the required test equipment and materials — construct or set up the RF POWER METERS — TYPES AND OPERATION per TM-TOOL-008, and use it to make valid measurements, achieving the accuracy stated in Chapter 7.

TLO-2: Given measurement results — interpret readings correctly, apply any required calculations, and determine pass/fail against the stated criterion.

Scope

the RF POWER METERS — TYPES AND OPERATION.

How to Use This Course

  1. Work units in order.
  2. For each unit: read the assigned TM chapter first, then read the unit, then answer the self-check questions.
  3. Self-check answers are at the bottom of each unit — try before looking.
  4. The checkpoint at the end of each unit is a go/no-go.
  5. Complete the Unit 5 lab before taking the final assessment.
  6. Passing score: 13/15 (87%). All calculation questions must be correct regardless of total score.
