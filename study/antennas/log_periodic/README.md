## How to Use This Course

1. Work units in order.
2. For each unit: **read the assigned TM chapter first**, then read the unit, then answer the self-check questions.
3. Self-check answers are at the bottom of each unit — try before looking.
4. The checkpoint at the end of each unit is a go/no-go.
5. Complete the Unit 4 and Unit 5 labs with a real antenna before taking the final assessment.
6. Passing score: 13/15 (87%). All calculation questions must be correct regardless of total score.
