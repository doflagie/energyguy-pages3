1. THEORY OF OPERATION
--------------------------------------------------------------------------------

An electrically short mobile antenna presents a capacitive reactance to the
feedline.  For a 2.4m whip, the characteristic impedance is:

    Zc = 60 × [ln(2 × 2.4 / 0.008) - 1]
       = 60 × [ln(600) - 1]
       = 60 × [6.397 - 1]
       = 60 × 5.397
       = 323.8 Ω  (use Zc = 324 Ω)

At any frequency below the antenna's natural resonance (~30 MHz for 2.4m), the
antenna looks like a capacitor in series with a small radiation resistance.  To
achieve resonance, we must add series INDUCTIVE reactance to cancel the capacitive
reactance of the short whip.

The loading coil provides this inductive reactance.  By varying how much coil is
in the circuit (by moving the wiper contact), we continuously tune the resonant
frequency across the HF spectrum.

The autotransformer tap provides impedance transformation to match the low
radiation resistance + coil resistance (typically 2–7 Ω) up toward 50 Ω coax.

    Fundamental equations:
    ─────────────────────
    Resonance condition:    XL = XC  (at operating frequency)
    Loading coil reactance: XL = 2π × f × L
    Required inductance:    L = XC / (2π × f)
    Radiation resistance:   Rrad = (λ/ℓ)² × Rfull   (short-antenna approx.)
    Efficiency:             η = Rrad / (Rrad + Rcoil)
    Autotransformer match:  Zmatch = Zant × (Ntap/Ntotal)²

--------------------------------------------------------------------------------

  TOP VIEW (looking down threaded rod axis):

         │    ╚═══════╤══════╝  │
         │         NUT │        │
         │     threaded│ rod    │
         └─────────────┴────────┘

  WIPER ASSEMBLY:
  - Brass driving nut threaded onto 1/4-20 rod
  - Phosphor-bronze brush spring contacts coil wire surface
  - Anti-rotation pin rides in slot in coil form wall
  - Flexible lead wire runs from brush to fixed output terminal
  - Normal force ~0.5N; contact resistance < 5 mΩ

  THREADED ROD TRAVEL:
  - 20 TPI = 1.27 mm/revolution
  - Motor: 2048 steps/rev
  - Steps per mm travel: 2048 / 1.27 = 1613 steps/mm
  - Steps per coil turn: (2.3mm pitch / 1.27mm/rev) × 2048 = 3710 steps/turn
  - Full coil (41 turns × 3710) = 152,110 steps total travel

5. AUTOTRANSFORMER / GAMMA MATCH ANALYSIS
--------------------------------------------------------------------------------

  The coil is tapped at turn 4 from the bottom.  The coax center conductor
  connects to this tap.  The coax shield connects to the wiper output.

  This creates an autotransformer with turns ratio:
        N_tap     4
       ─────── = ── = 0.0976
       N_total   41

  Impedance transformation ratio:
        Zmatch = Zant × (Ntap/Ntotal)²
               = Zant × (4/41)²
               = Zant × 0.00952

  For a given Zant (feed impedance at the wiper point):
  ┌──────────┬───────────┬──────────────┬──────────────────┐
  │  Band    │  Zant(Ω)  │  Zmatch(Ω)   │  Ideal Ntap      │
  ├──────────┼───────────┼──────────────┼──────────────────┤
  │  10m     │  5.23     │  0.050       │  13.26T for 50Ω  │
  │  12m     │  4.22     │  0.040       │  11.91T for 50Ω  │
  │  15m     │  3.32     │  0.032       │  10.57T for 50Ω  │
  │  17m     │  2.81     │  0.027       │   9.72T for 50Ω  │
  │  20m     │  2.44     │  0.023       │   9.06T for 50Ω  │
  │  30m     │  2.58     │  0.025       │   9.30T for 50Ω  │
  │  40m     │  3.41     │  0.032       │  10.71T for 50Ω  │
  │  60m     │  4.73     │  0.045       │  12.61T for 50Ω  │
  │  80m     │  7.16     │  0.068       │  15.52T for 50Ω  │
  └──────────┴───────────┴──────────────┴──────────────────┘

  NOTE: The fixed tap at 4T does NOT provide a 50Ω match on any band.
  It provides a starting point for the SWR-sensing autotuner to fine-tune
  wiper position.  The autotuner seeks the wiper position that minimizes SWR.
  An external shunt-C tuner or the built-in L-net can trim the residual mismatch.

  AUTOTRANSFORMER SCHEMATIC:
                                           ← to whip
       ┌─────────────────────────────────┐
       │         LOADING COIL            │
       │  (41 turns wound on form)       │
       │                                 │
  ─────┼──────── TAP (turn 4) ─── COAX CENTER CONDUCTOR ──→
       │                                 │
  ─────┼──────── WIPER OUTPUT ─── COAX SHIELD ────────────→
       │                                 │
       └─────────────────────────────────┘
           (bottom of coil = counterpoise/ground bus)

  Math:
    V_out/V_in  = N_tap/N_total = 4/41
    I_out/I_in  = N_total/N_tap = 41/4
    Z_out/Z_in  = (N_tap/N_total)² = (4/41)² = 0.00952
    If Z_in = 5000 Ω, then Z_out = 47.6 Ω ≈ 50 Ω  [for that specific case only]

6. WHEELER FORMULA AND COIL DESIGN CALCULATIONS
--------------------------------------------------------------------------------

  Wheeler's formula for single-layer air-core solenoid (SI adjusted):

       14.0625 × N²
  L = ──────────────────   [µH]
       85.73 + 5.842 × N

  where N = number of turns active

  Physical coil parameters:
    - Form OD:    75 mm
    - Form length: 110 mm total, 95 mm winding area
    - Wire:        #14 AWG, 2.0 mm diameter
    - Pitch:       2.3 mm center-to-center
    - Max turns:   41 (95mm / 2.3mm = 41.3, use 41)
    - Winding OD:  75mm + 2×2.0mm = 79 mm (includes wire diameter)

    20m: 100W × 52.0% = 52W radiated ERP
