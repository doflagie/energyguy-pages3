DIRECTIONAL COUPLER THEORY:
──────────────────────────────────────────────────────────────────────────────
A directional coupler separates the incident (forward) wave from the reflected
wave on a transmission line by combining two coupling mechanisms in correct phase:

  Magnetic coupling:   Proportional to line current I_line (via transformer)
  Electric coupling:   Proportional to line voltage V_line (via resistive network)

  Forward wave:  V_mag and V_elec are IN PHASE  → add  → V_fwd ≠ 0
  Reverse wave:  V_mag and V_elec are OUT OF PHASE → cancel → V_rev ≈ 0

MATH:
  V_fwd = (V_line + I_line × Z₀) / 2     (incident voltage wave)
  V_rev = (V_line − I_line × Z₀) / 2     (reflected voltage wave)
  Z₀ = 50 Ω (system impedance)

  ρ = |V_rev| / |V_fwd| = √(P_rev / P_fwd)     (reflection coefficient)
  SWR = (1 + ρ) / (1 − ρ)                       (standing wave ratio)
  RL  = −20 × log₁₀(ρ)  [dB]                    (return loss)
  ML  = −10 × log₁₀(1 − ρ²) [dB]               (mismatch loss)

================================================================================
  SCHEMATIC — AD8307 DUAL LOG-AMP IMPLEMENTATION (PREFERRED)
================================================================================

  For calibrated absolute power reading, replace diode detectors with AD8307:

  Vfwd_RF ──[C3: 100nF AC]──[AD8307 #1]──┬── VOUT_fwd (DC, 25mV/dB)──► GPIO35
                                  │       │
                                 3V3     [C5: 4.7nF]
                                  │       │
                                 GND     GND

  Vrefl_RF──[C4: 100nF AC]──[AD8307 #2]──┬── VOUT_refl (DC, 25mV/dB)──► GPIO39
                                  │       │
                                 3V3     [C6: 4.7nF]
                                  │       │
                                 GND     GND

  AD8307 pin connections:
    Pin 1 (INP)  ← RF signal via 100nF coupling cap
    Pin 2 (INM)  → 52.3Ω to GND (input termination resistor for 50Ω match)
    Pin 3 (OFS)  → 10kΩ to GND (offset null; leave open or connect for calibration)
    Pin 4 (GND)  → GND
    Pin 5 (VPOS) → 3.3V supply via 10Ω decoupling + 100nF to GND
    Pin 6 (ENB)  → 3.3V (enable; high = active, low = shutdown)
    Pin 7 (CLPF) → 4.7nF to GND (output smoothing filter)
    Pin 8 (VOUT) → ESP32 ADC (GPIO 35 or 39)

  POWER CALCULATION:
    V_out_mV = 25 × (P_in_dBm + 84)    [AD8307 transfer function]

    Solving for P_in:
    P_in_dBm = (V_out_mV / 25) − 84

    After coupler correction (coupling_dB ≈ 20 dB):
    P_actual_dBm = P_detected_dBm + 20.0

    Power in watts:
    P_watts = 10 ^ ((P_actual_dBm − 30) / 10)

  DYNAMIC RANGE:
    AD8307: −73 to +17 dBm (90 dB range)
    After 20 dB coupler: −53 to +37 dBm measurable at antenna port
    For QRP 5W (+37 dBm): at upper limit of range — add 6 dB pad if needed
    For 100W (+50 dBm): add 10–13 dB attenuator pad before coupler input

  COUPLER DIRECTIVITY COMPARISON
================================================================================

  ┌───────────────────────────────────────┬──────────────┬──────────────────┐
  │ Coupler Type                          │ Directivity  │ Frequency Range  │
  ├───────────────────────────────────────┼──────────────┼──────────────────┤
  │ Simple resistive bridge (diode only)  │ 20–25 dB     │ DC–150 MHz       │
  │ Bruene (FT-37-43 + R network)         │ 30–35 dB     │ 1.8–30 MHz       │
  │ Dual AD8307 + Bruene coupler          │ 35–40 dB     │ 1–50 MHz         │
  │ Commercial (Mini-Circuits ZFDC-10-5)  │ 40–45 dB     │ per model        │
  └───────────────────────────────────────┴──────────────┴──────────────────┘

  Directivity effect on SWR measurement accuracy:
    30 dB directivity: error < 0.05 SWR units at SWR < 3:1
    25 dB directivity: error < 0.10 SWR units at SWR < 2:1
    20 dB directivity: marginal; use only for relative indication

  For screwdriver antenna (efficiency often < 50% on low bands): even 25 dB
  directivity is adequate for finding the minimum SWR null. Absolute accuracy
  is secondary to finding the resonant dip.

  IMPORTANT NOTE FOR SCREWDRIVER ANTENNAS:
  On low-efficiency bands (40m, 80m), the antenna may show SWR = 2:1 or 3:1
  at the TRANSCEIVER even when the antenna is properly tuned to resonance.
  This occurs because:
  1. Low Rrad (< 5Ω) requires precise coil position for resonance
  2. Small coil position errors = large frequency offset = large SWR
  3. The L-network / tap matching is a compromise across all bands

  Always tune for the MINIMUM SWR reading, not an absolute target value.
  A minimum of 2.5:1 on 80m with a 2.4m whip is normal and represents proper tune.
  Efficiency, NOT SWR, determines actual radiated power on low bands.

================================================================================
  SWR vs. EFFICIENCY — COMBINED LOSS ESTIMATE
================================================================================

  True radiated power = P_transmitter × (1 − mismatch_loss) × efficiency

  Example: 100W on 80m with SWR 2:1 and 1.2% antenna efficiency:
    Mismatch loss at SWR 2:1: 11.1% lost = 88.9% enters antenna system
    Antenna efficiency: 1.2% of input power radiated
    P_radiated = 100 × 0.889 × 0.012 = 1.07 W

  Example: 100W on 20m with SWR 1.5:1 and 52% efficiency:
    Mismatch loss: 4.0% → 96% enters antenna
    P_radiated = 100 × 0.96 × 0.52 = 49.9 W

  Bottom line: On 10m–17m the screwdriver is competitive with full-size antennas.
               On 40m–80m it is a strictly QRP/emergency antenna regardless of power.
