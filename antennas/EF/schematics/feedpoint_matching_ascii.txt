================================================================================
  EFQW FEEDPOINT MATCHING NETWORK                        TM-EF-SCH-001 Rev A
  L-Network Manual Tuning, HF Bands (160m – 10m)
================================================================================

PURPOSE: Transform antenna feedpoint impedance (~35Ω) to coaxial feed (50Ω).
         Variable capacitor allows manual SWR minimization across band.

MATCHING THEORY — L-NETWORK (LOW-PASS):
────────────────────────────────────────
  Q   = √(Z_source/Z_load − 1) = √(50/35 − 1) = 0.655
  Xs  = Q × Z_load = 0.655 × 35 = 22.9 Ω  (series arm, inductive)
  Xp  = Z_source/Q = 50 / 0.655 = 76.4 Ω  (shunt arm, capacitive)

  At 7.150 MHz (40m):
    Ls = 22.9 / (2π × 7.15e6) = 0.510 µH
    Cp = 1 / (2π × 7.15e6 × 76.4) = 291 pF

  Variable Cp allows tuning across ±150 kHz band segment.
  See resonator_winding_tables.csv for all band values.

  SCHEMATIC — VHF GAMMA MATCH (6m, 2m)

  Main element (QW vertical)
  │
  │←──── gamma rod (15% of element length)
  │      3mm rod, parallel to main element
  │      connected to center of coax
  │
  ├────[C_gamma: 0–30 pF variable trimmer]──── coax center
  │
  ╪ (feedpoint, base of element)
  │
 [gnd plane: 4 bent radials at 45°]──── coax shield

  Gamma cap: Teflon trimmer or silver mica compression type.
