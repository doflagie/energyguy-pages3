================================================================================
  1. MAGNETIC LOOP ANTENNA OVERVIEW
================================================================================

  A Small Transmitting Loop (STL) is an electrically small loop antenna where
  the circumference is much less than one wavelength (C < 0.3λ). It operates
  as a magnetic dipole, resonated by a parallel capacitor to form a high-Q
  LC tank circuit.

  The pool noodle (polyethylene foam, εᵣ ≈ 1.05, μᵣ = 1.0) serves only as a
  structural form. Its RF properties are negligible (tan δ < 0.001).

  Two configurations:
    STL (HF, 160m–10m): Loop resonated by variable capacitor, fed by Faraday loop
    Quad (VHF/UHF, 6m–20cm): Full-wave resonant loop, fed at bottom center

  2. EQUIVALENT CIRCUIT — HF STL
================================================================================

  The STL at resonance is modeled as:

  ┌─────────────────────────────────────────────────────────────────────────┐
  │                                                                         │
  │     MAIN LOOP EQUIVALENT CIRCUIT                                        │
  │                                                                         │
  │     ┌──────[L_loop]──────[Rrad]──────[Rloss]──────┐                   │
  │     │                                               │                   │
  │     │          ┌──────[C_tune]──────┐              │                   │
  │     │          │    (variable cap)  │              │                   │
  │     └──────────┘                   └──────────────┘                   │
  │                                                                         │
  │                    ↕  magnetic coupling  ↕                             │
  │                                                                         │
  │     ┌──────[Lc_loop]──────────────────────────────┐                   │
  │     │          COUPLING LOOP (1/5 main loop)       │──── 50Ω coax     │
  │     └─────────────────────────────────────────────┘                   │
  │                                                                         │
  │  L_loop = loop inductance (H)        Rrad = radiation resistance (Ω)   │
  │  Rloss  = wire loss resistance (Ω)   C_tune = resonating cap (F)       │
  │  Lc     = coupling loop inductance   k = coupling coefficient           │
  └─────────────────────────────────────────────────────────────────────────┘

  3. FORMULAS AND DERIVATIONS
================================================================================

  Physical constants:
    μ₀ = 4π × 10⁻⁷  H/m
    ρ  = 1.72 × 10⁻⁸ Ωm  (copper resistivity)
    σ  = 5.80 × 10⁷  S/m (copper conductivity)

  ── 3.1  Single-Turn Square Loop Inductance ──────────────────────────────

    L₁ = (2μ₀/π) × s × [ln(2s/a) − 0.774]  [H]

    where:  s = side length (m)
            a = wire radius (m)  [#14 AWG: a = 0.000814 m]
            ln() = natural logarithm

    Example: s=1.2m, a=0.000814m
    L₁ = (2×4π×10⁻⁷/π) × 1.2 × [ln(2×1.2/0.000814) − 0.774]
       = 8×10⁻⁷ × 1.2 × [ln(2948) − 0.774]
       = 9.6×10⁻⁷ × [8.000 − 0.774] = 6.94 μH

  ── 3.2  Multi-Turn Inductance ───────────────────────────────────────────

    L_N = N² × L₁ × k_N    [H]

    where:  N    = number of turns
            k_N  = Nagaoka coefficient ≈ 0.85 for close-wound turns

  ── 3.3  Radiation Resistance ────────────────────────────────────────────

    Rrad = 197 × (4Ns/λ)⁴  [Ω]

    This is the power that leaves as radiation. For small loops (4Ns << λ)
    Rrad is very small — milliohms to ohms.

    Example: N=2, s=1.2m, λ=41.93m (40m band)
    4Ns/λ = 9.6/41.93 = 0.2289
    Rrad = 197 × 0.00274 = 0.541 Ω

  ── 3.4  Skin Depth and Loss Resistance ──────────────────────────────────

    δ = √(ρ / (π × f × μ₀))  [m]  (skin depth)

    Example: f = 7.15 MHz
    δ = √(1.72×10⁻⁸ / (π × 7.15×10⁶ × 4π×10⁻⁷)) = 24.68 μm

    Rloss = (total wire length) / (σ × 2πa × δ)  [Ω]

    total wire = 4 × N × s  [m]

    Example: N=2, s=1.2m, f=7.15MHz
    wire = 9.6m
    Rloss = 9.6 / (5.8×10⁷ × 2π × 0.000814 × 24.68×10⁻⁶)
          = 9.6 / 7.329 = 1.311 Ω

  ── 3.5  Efficiency ──────────────────────────────────────────────────────

    η = Rrad / (Rrad + Rloss) × 100%

    Example (40m, 2T, s=1.2m):
    η = 0.541 / (0.541 + 1.311) × 100% = 29.2%

    A well-built magnetic loop is NOT a low-efficiency antenna on 20m-10m.
    On 160m-80m efficiency is 1-22% — low but comparable to a short whip.

  ── 3.6  Q Factor ────────────────────────────────────────────────────────

    Q = ωL_N / Rloss = (2πf × L_N) / Rloss  [dimensionless]

    High Q means:
      - Narrow bandwidth (must re-tune when changing frequency)
      - High capacitor voltage
      - High efficiency for given Rloss

  ── 3.7  Bandwidth ───────────────────────────────────────────────────────

    BW = f / Q  [Hz]   (−3 dB bandwidth)

    IMPORTANT: Magnetic loop antennas have very narrow bandwidth.
    Typical values: 160m → 2.1 kHz; 40m → 8.9 kHz; 20m → 13 kHz
    You MUST re-tune the capacitor when changing frequency by more than ~5 kHz
    on low bands, or ~15 kHz on high HF bands.

  ── 3.8  Resonating Capacitor ────────────────────────────────────────────

    C = 1 / ((2πf)² × L_N)  [F]

    The capacitor must be variable over a range ±3× the center value
    to cover manufacturing tolerances and fine-tune across the band.

  ── 3.9  Capacitor Voltage ───────────────────────────────────────────────

    I = √(P / (Rrad + Rloss))         [A]   (loop current)
    Vc = I × 2πf × L_N                [V]   (peak voltage across cap)

    At resonance, XL = XC, so this is the Q-amplified voltage.
    Vc ≈ √(P × Q² × Rloss)  [V peak]

================================================================================
  4. MULTI-TURN SCALING SUMMARY
================================================================================

  For a fixed loop size, adding turns improves efficiency dramatically:

  N  │ Rrad scales as │ Rloss scales as │ η improvement │ C scales as
  ───┼─────────────────┼─────────────────┼───────────────┼─────────────
  1  │ 1×              │ 1×              │ baseline      │ 1×
  2  │ 16×             │ 2×              │ significant   │ 1/4×
  3  │ 81×             │ 3×              │ large         │ 1/9×
  4  │ 256×            │ 4×              │ very large    │ 1/16×

  Note: Multi-turn reduces C needed → smaller, lower-voltage capacitor
  Note: Multi-turn reduces Q (Rloss increases faster) → wider bandwidth

  6. DIRECTIVITY PATTERN
================================================================================

  HF STL (magnetic loop) radiation pattern:

  Horizontal plane (looking down — figure-8, nulls in axis of loop):

             BROADSIDE
                 │
                 │  max
          ╭──────┴──────╮
         ╱               ╲
  NULL ─┤                 ├─ NULL  ← loop plane
         ╲               ╱        (perpendicular to loop is null)
          ╰──────┬──────╯
                 │  max
             BROADSIDE

  Vertical plane (omnidirectional — same as horizontal dipole on its edge):
  Maximum radiation broadside to the loop plane.
  Orient loop for maximum toward desired station.

  VHF/UHF Quad Loop Pattern:
  Square quad has gain ≈ 2 dBd broadside.
  Horizontally polarized when loop is vertical, fed at bottom center.
  Vertically polarized when loop is horizontal, fed at one side.

================================================================================
  7. OPERATING NOTES
================================================================================

  7.1  TUNING PROCEDURE
       Step 1: Set capacitor to band default position.
       Step 2: Apply low power RF (< 1W); observe SWR meter.
       Step 3: Slowly rotate capacitor for SWR minimum (the "dip").
       Step 4: If SWR at minimum > 1.5:1, adjust coupling loop size.
       Step 5: Repeat Steps 3–4 until SWR < 1.5:1.

  7.2  RE-TUNING FOR FREQUENCY CHANGE
       Due to narrow bandwidth, re-tune for every 5–10 kHz QSY on 160m/80m,
       every 10–20 kHz on 40m/20m, every 20–40 kHz on 17m–10m.
       Motor-driven capacitor (auto-tune) eliminates this burden.

  7.3  POOL NOODLE RF PROPERTIES
       Polyethylene foam: εᵣ ≈ 1.05, μᵣ = 1.0, tan δ < 0.001 at HF.
       The noodle acts as a rigid, weatherproof form with negligible
       effect on loop inductance or radiation efficiency.

  7.4  CURRENT DISTRIBUTION
       When loop circumference << λ (C/λ < 0.1), current is nearly
       uniform around the loop. This simplifies analysis and means all
       parts of the loop contribute equally to radiation.
