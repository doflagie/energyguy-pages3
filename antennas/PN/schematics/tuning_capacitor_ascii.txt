================================================================================
  3. AIR VARIABLE CAPACITOR DESIGN
================================================================================

  3.1  Standard Air Variable Construction

    Two sets of interleaved aluminum plates, separated by air gap.
    Rotating one set (rotor) changes meshed area → changes capacitance.

    C (pF) ≈ ε₀ × n × A / d

    where:  ε₀ = 8.854 × 10⁻¹² F/m
            n  = number of plate gaps (= N_plates − 1)
            A  = plate overlap area (m²)
            d  = plate spacing (m)

  3.2  Split-Stator (Butterfly) Capacitor

    Two stator sections with one common rotor. Each stator section
    contributes half the capacitance; in series → high voltage rating.

    ┌───────────────────────────────────────────────────────────────┐
    │   BUTTERFLY CAPACITOR CROSS-SECTION                          │
    │                                                               │
    │   STATOR A          ROTOR          STATOR B                  │
    │                                                               │
    │   ┤  ┤  ┤  ┤    ┤  ┤  ┤  ┤  ┤    ┤  ┤  ┤  ┤               │
    │   │  │  │  │    │  │  │  │  │    │  │  │  │                 │
    │   ┤  ┤  ┤  ┤──[axis]──┤  ┤  ┤  ┤──┤  ┤  ┤  ┤               │
    │   │  │  │  │    │  │  │  │  │    │  │  │  │                 │
    │   ┤  ┤  ┤  ┤    ┤  ┤  ┤  ┤  ┤    ┤  ┤  ┤  ┤               │
    │                                                               │
    │   Loop connection:  Stator A ─── loop ─── Stator B           │
    │                     Rotor floats (connected to frame ground)  │
    │                                                               │
    │   Advantage: rotor at RF ground (shaft OK to touch when OFF)  │
    │   High-voltage rating: each stator carries full Vc           │
    └───────────────────────────────────────────────────────────────┘

  3.3  Vacuum Capacitor (160m, 80m recommended)

    Electrodes enclosed in glass/ceramic envelope evacuated to < 10⁻⁵ torr.
    Air breakdown eliminated → compact design despite kV ratings.

    Typical: Jennings CSVF or equivalent
    Range: 5–500 pF available; choose 5–50 pF or 10–100 pF for HF loops
    Voltage: 15 kV or 25 kV ratings standard
    Drive: requires rotary motor (≈ 10 turns shaft from min to max)

================================================================================
  6. CAPACITOR SAFETY — BLEEDER RESISTOR
================================================================================

  REQUIRED: 100 kΩ, 1W resistor permanently wired across capacitor terminals.

  Purpose: Discharge capacitor after TX ends to prevent shock hazard.

  Time constant:
    τ = R × C  [seconds]
    160m (C=41.7pF): τ = 100,000 × 41.7×10⁻¹² = 4.17 µs → safe in < 1 ms
    20m  (C=7.4pF):  τ = 100,000 × 7.4×10⁻¹²  = 0.74 µs → safe in < 0.1 ms

  Power dissipation at rated voltage (100W):
    P_bleeder = Vc² / R = (7523/√2)² / 100,000  = 0.283 W  (20m, 100W)
    → 1W resistor adequate. Use 2W for 160m/80m at high power.

  Discharge procedure before capacitor access:
    1. Key PTT OFF; confirm TX terminated.
    2. Wait 10× τ = 50 µs (per bleeder calculation above).
    3. Short capacitor terminals momentarily with insulated clip lead.
    4. Measure with high-impedance voltmeter (>10 MΩ input) to confirm 0V.
    5. Then proceed to access capacitor.
