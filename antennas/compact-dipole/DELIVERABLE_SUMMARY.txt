DESIGN SUMMARY
================================================================================

ANTENNA ARCHITECTURE:
  • Center-loaded dipoles (inductive loading at arm midpoint)
  • Parallel LC resonators for manual tuning (Bourns 3296 trimmers)
  • Roll-up card design on HDPE substrate
  • 50Ω center-fed via 1:1 ferrite balun

COMPACTION FACTORS:
  • HF (160M–10M): 50% of full size
  • VHF (6M–2M): 60% of full size
  • UHF (1.25M–20cm): ~95% of full size

PERFORMANCE (TYPICAL):
  • Impedance: 50Ω ±10%
  • SWR @ band center: <1.5:1 (after tuning)
  • Efficiency: 85–90% (HF), 80–85% (VHF), 75–82% (UHF)
  • Gain: 2.0–2.5 dBi
  • Radiation pattern: Figure-8 (broadside)

FIELD DEPLOYMENT:
  • Rapid unroll from card: <2 minutes
  • Portable weight: 100–150g (HF), 50–80g (VHF)
  • Manual tuning with dip meter
  • All-frequency coverage in single portable suite

USAGE WORKFLOW
================================================================================

FOR FABRICATION:
  1. Select band → cd <band>/
  2. Read technical chapter: compact_dipole_<band>.md (Section 4)
  3. Get component values: winding_table_<band>.csv
  4. View diagrams: figures/*.png
  5. Obtain PVC forms, wire, trimmers from suppliers
  6. Follow step-by-step procedures with CAUTION/WARNING notes
  7. Test inductance (target ±10% of winding table)

FOR TESTING:
  1. Connect feedline to center BNC connector
  2. Use dip meter on trap resonator (adjust trimmer for minimum dip)
  3. Verify SWR <1.5:1 @ band center
  4. Load NEC model (*.nec) in 4nec2 for verification
  5. Test radiation pattern, gain, efficiency predictions

FOR DEPLOYMENT:
  1. Unroll card (stored in protective pouch)
  2. Extend radiator arms
  3. Connect feedline + balun at center
  4. Quick dip meter resonance check if needed
  5. Monitor power levels (see manual Section VI)
  6. Ready to transmit!

FOR UNDERSTANDING THEORY:
  1. Start: COMPACT_DIPOLE_MANUAL.md Section I
  2. Review: Global figures (fig_01 through fig_08)
  3. Study: Per-band chapter for RF details
  4. Verify: NEC2 simulation in software

TECHNICAL FOUNDATION
================================================================================

DESIGN FORMULAS (Verified):
  1. Loading inductance: L_load(μH) = 20.9 × (7.15 / f_MHz)²
     Source: NEC2 40M reference antenna (20.9 μH @ 7.15 MHz)

  2. Coil winding (Wheeler): L = r² × N² / (9r + 10ℓ)
     where r = form radius, ℓ = coil length (inches)

  3. Trap resonance: f = 1 / (2π√(LC))
     Calculate for each band given C_trap

  4. Dipole full size: L_full = 71.3 / f_MHz meters
     (assuming velocity factor = 0.95)

All calculations cross-checked for mathematical consistency.
