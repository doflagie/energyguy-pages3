1.0  OVERVIEW
================================================================================

  The SWR bridge and directional coupler sits between the transceiver output
  and the L-network/loading coil assembly.  It samples forward and reflected
  power simultaneously, allowing:

    a) Real-time SWR display during transmit
    b) Automatic tuning feedback (ESP32 → C_shunt varactor control)
    c) Logging of SWR vs. frequency for field calibration records
    d) Protection alerts if SWR exceeds threshold (fold-back or warning)

  TWO IMPLEMENTATIONS DESCRIBED:

    Section 3:  Bruene coupler with diode detectors (simple, low-cost)
    Section 4:  Bruene coupler + AD8307 log amps (accurate, 50 dB range)

  Either implementation feeds the same ESP32 ADC inputs.

3.0  BRUENE DIRECTIONAL COUPLER SCHEMATIC
================================================================================

  THEORY:
    The Bruene coupler uses a current transformer (single-turn primary through
    a toroid, multi-turn secondary) combined with a voltage sampling point.
    Forward wave voltage is the sum of V_line and V_coupled; reflected wave
    is the difference.  Diode detectors convert to DC for the ADC.

  CONSTRUCTION:
    Core:      FT-37-43 (Mix 43, OD=9.5mm)  — suitable 1.8–30 MHz
    Primary:   1 turn = pass the coax center conductor through the core hole
    Secondary: 10 turns of 28 AWG enameled wire, close-wound

  SCHEMATIC:

                  ┌──────────────────────────────────────────────┐
                  │           BRUENE DIRECTIONAL COUPLER          │
                  │                                               │
  From Coax ─────┼───┬──────────────────────────────┬───────────┼──── To L-net
  (center)       │   │    ● ← 1T primary             │           │
                 │  FT-37-43                      R_load=51Ω    │
                 │  (pass-thru)                       │           │
                 │   │                               GND          │
                 │   │ 10T secondary                              │
                 │   ├─────────────────────────────────────────┐  │
                 │   │                                         │  │
                 │   ├──[R1 51Ω]──[D1 1N5711]──┬──────────────┘  │
                 │   │                          │                  │
                 │   │                         [C1 100nF]         │
                 │   │                          │                  │
                 │   │                         GND → Vfwd DC      │
                 │   │                          │                  │
                 │   │                     [GPIO35 on ESP32]      │
                 │   │                                             │
                 │   └──[R3 51Ω]──[D2 1N5711◄]──┬────────────────┘
                 │             (reversed)        │
                 │                              [C2 100nF]
                 │                               │
                 │                              GND → Vrefl DC
                 │                               │
                 │                          [GPIO39 on ESP32]
                 │                                               │
                 └──────────────────────────────────────────────┘

  COMPONENT LIST — BRUENE VERSION:

    T1:  FT-37-43 toroid, 1T primary (pass-thru), 10T secondary 28 AWG
    R1:  51 Ω ¼W metal film (forward detector load)
    R2:  51 Ω ¼W metal film (line termination, not always shown — see note)
    R3:  51 Ω ¼W metal film (reflected detector load)
    D1:  1N5711 Schottky (forward detector)
    D2:  1N5711 Schottky (reflected detector, installed reversed)
    C1:  100 nF ceramic (forward filter cap)
    C2:  100 nF ceramic (reflected filter cap)

  NOTE on R2 (voltage termination resistor):
    In the full Bruene design a 51 Ω resistor across the secondary provides
    a resistive voltage sample in quadrature with the coupled current.
    The vector sum/difference at D1 and D2 gives forward and reflected ports.
    Without R2 the coupler reverts to a simple current-transformer type with
    reduced directivity.  Include R2 for best directivity.

  PCB LAYOUT NOTES:
    ► Keep detector components (R, D, C) within 20 mm of toroid.
    ► Ground plane directly under detector circuit.
    ► Route Vfwd and Vrefl traces away from RF line with ≥ 5 mm clearance.
    ► Use twisted-pair or shielded wire from board to ESP32 if > 50 mm.

4.0  AD8307 DUAL LOG-AMP VERSION
================================================================================

  THEORY:
    The AD8307 is a logarithmic amplifier with 500 MHz bandwidth and
    92 dB dynamic range.  Output is 25 mV per dB, with 0 dBm corresponding
    to approximately 2.1 V output.  This gives accurate power measurement
    from -75 dBm to +17 dBm without detector diode temperature errors.

5.0  SWR MATH — CALCULATIONS AND FORMULAS
================================================================================

  INPUT: ADC readings from GPIO35 (Vfwd_adc) and GPIO39 (Vrefl_adc)
  ADC:   12-bit, 3.3V reference → 3.3V / 4096 = 0.806 mV/count

  STEP 1 — Convert ADC counts to millivolts:

    V_fwd_mV  = Vfwd_adc  × 0.806
    V_refl_mV = Vrefl_adc × 0.806

  STEP 2 — Convert AD8307 voltage to dBm:

    For AD8307:  Vout = 25 mV/dB × (P_dBm + 84)
    Therefore:   P_dBm = (V_mV / 25) - 84

    P_fwd_dBm  = (V_fwd_mV  / 25) - 84
    P_refl_dBm = (V_refl_mV / 25) - 84

  STEP 3 — Convert dBm to watts:

    P_fwd_W  = 10^( (P_fwd_dBm  - 30) / 10 )
    P_refl_W = 10^( (P_refl_dBm - 30) / 10 )

  STEP 4 — Reflection coefficient:

    rho = 10^( (P_refl_dBm - P_fwd_dBm) / 20 )

  STEP 5 — SWR:

    SWR = (1 + rho) / (1 - rho)

  STEP 6 — Return Loss (dB):

    RL_dB = P_fwd_dBm - P_refl_dBm   [positive value; higher = better]

  STEP 7 — Mismatch Loss (power lost to reflection):

    ML_dB = -10 × log10(1 - rho²)    [power lost in dB; 0 = perfect match]

  EXAMPLE CALCULATION (40m, good tune):
    Vfwd_adc  = 2700 counts → 2177 mV → P_fwd  = (2177/25) - 84 = +3.1 dBm
    Vrefl_adc =  480 counts →  387 mV → P_refl = (387/25)  - 84 = -68.5 dBm

    (In practice both readings will be much higher on 10 W TX — the Bruene
     coupler samples a fixed fraction of line power.  The ratio is what counts.)

    rho = 10^( (-68.5 - 3.1) / 20 ) = 10^(-3.58) = 0.000263 → SWR ≈ 1.001
    [This is an example of a nearly perfect match; real field results vary.]

  CALIBRATION:
    ► Terminate RF_OUT in precision 50 Ω load.
    ► Apply known power from signal generator.
    ► Record Vfwd_adc; derive calibration offset K:
        K = P_known_dBm - ((V_fwd_mV / 25) - 84)
    ► Add K to all subsequent P_dBm calculations.
    ► Calibrate both channels independently.

6.0  COUPLER DIRECTIVITY COMPARISON TABLE
================================================================================

  Directivity = isolation between forward and reflected ports when RF_OUT is
  terminated in a perfect 50 Ω load.  Higher is better.

  ┌─────────────────────────────────────────┬────────────────┬──────────────┐
  │ Coupler Type                            │ Directivity    │ Notes        │
  ├─────────────────────────────────────────┼────────────────┼──────────────┤
  │ Simple diode bridge (resistive)         │  20–25 dB      │ Low cost;    │
  │                                         │                │ temperature  │
  │                                         │                │ sensitive    │
  ├─────────────────────────────────────────┼────────────────┼──────────────┤
  │ Bruene coupler + FT-37-43 toroid        │  30–35 dB      │ Good HF      │
  │ (diode detectors)                       │                │ performance  │
  │                                         │                │ 1.8–30 MHz   │
  ├─────────────────────────────────────────┼────────────────┼──────────────┤
  │ AD8307 + Bruene coupler                 │  35–40 dB      │ Best dynamic │
  │ (log-amp detectors)                     │                │ range; wide  │
  │                                         │                │ temp range   │
  ├─────────────────────────────────────────┼────────────────┼──────────────┤
  │ Tandem match (dual-core)                │  40–45 dB      │ Requires     │
  │                                         │                │ precise      │
  │                                         │                │ component    │
  │                                         │                │ matching     │
  ├─────────────────────────────────────────┼────────────────┼──────────────┤
  │ Directional coupler (transmission line) │  20–30 dB      │ VHF/UHF      │
  │ (λ/4 coupled-line PCB)                  │                │ preferred;   │
  │                                         │                │ HF too large │
  └─────────────────────────────────────────┴────────────────┴──────────────┘

  DIRECTIVITY IMPACT ON SWR MEASUREMENT ACCURACY:
    A coupler with 30 dB directivity has a reflected signal floor 30 dB below
    the forward signal when load is perfect 50 Ω.  This limits SWR accuracy:

      Directivity 20 dB → SWR reading error ≈ ±0.1 at SWR 1.5:1
      Directivity 30 dB → SWR reading error ≈ ±0.03 at SWR 1.5:1
      Directivity 40 dB → SWR reading error ≈ ±0.01 at SWR 1.5:1

  For a loading-coil tuner where target SWR < 1.5:1, 30 dB directivity
  (Bruene + toroid) is adequate.  The AD8307 version eliminates detector
  nonlinearity as an error source.

  TUNER TARGET:  SWR ≤ 1.5:1 at transceiver output (after L-network).
  PROTECTION:    Alert or fold-back if SWR > 3:1 at ESP32 firmware level.

  ADDITIONAL LOSS REFERENCE — COAX ATTENUATION AT 100W:

    SWR 1.5:1 in 10m of RG-58 (0.25 dB/m at 14 MHz):
      Coax loss:       2.5 dB (one-way)
      Mismatch loss:   0.18 dB
      Total:           2.68 dB → 54 W delivered  (vs. 56 W for perfect match)
      Difference:      0.18 dB — negligible; coax loss dominates

    MORAL: On HF, coax length matters far more than SWR < 2:1.
    Minimize coax length and SWR simultaneously for best efficiency.

    GPIO35  ← ADC1_CH7  — Vfwd from AD8307 #1 (or diode fwd detector)
    GPIO39  ← ADC1_CH3  — Vrefl from AD8307 #2 (or diode refl detector)
    GPIO34  ← ADC1_CH6  — Band switch input (resistor divider, 6 bands)
    GPIO25  → DAC1       — Varactor control voltage (0–3.3V → cap tuning)
    GPIO26  → DAC2       — Spare (future: motor direction or second varactor)
    GPIO18  → SPI SCK    — CYD display (if local display on SWR board)
    GPIO19  → SPI MISO   — CYD display
    GPIO23  → SPI MOSI   — CYD display
    GPIO5   → SPI CS     — CYD display CS
    GPIO4   ← Button 1   — Manual tune up
    GPIO0   ← Button 2   — Manual tune down
    GPIO2   → LED        — SWR OK indicator (green)
    GPIO15  → LED        — SWR high indicator (red)

  FIRMWARE TUNING LOOP (pseudo-code):

    loop:
      read Vfwd_adc, Vrefl_adc
      calculate SWR
      if SWR > 1.5:
        increment or decrement varactor_voltage by small step
        update display
        wait 50ms (allow L-network to settle)
      else:
        hold current varactor_voltage
        display SWR + power readings
      if SWR > 3.0:
        alert_high_swr()   // flash red LED, send BLE notification
