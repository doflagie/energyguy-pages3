    │░░░░░░░░░░░░░░░░░░░░░░░░░░░│  ← 3-inch NYLON WEBBING (substrate + dielectric)
    │▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓│  ← STRIP B: 2" Al/Cu tape, BACK FACE (stub only)

    TRANSMISSION LINE (stub section):
    Z₀ = (η₀/√εᵣ) × (d/w) = (377/√3.0) × (3mm/50.8mm) ≈ 13Ω
    VF_stub = 1/√εᵣ = 1/√3.0 = 0.577

4. BOTTOM FOLD — SHORT CIRCUIT DETAIL
========================================

                 ← 3" webbing width →
    ──────────────────────────────────────  ← BOTTOM EDGE of webbing
    │  STRIP A  │  WEBBING BODY  │         │  STRIP A
    │           │                │         │  (front)
    │           ↓                ↓         │
    │  ─────────────────────────────────   │
    │  [fold bottom 20mm upward onto BACK] │
    │           ↑                          │
    │  STRIP A OVERLAP ON BACK FACE:       │
    │  connects to STRIP B bottom end      │
    └──────────────────────────────────────┘

    Step 1: Leave 20mm of Strip A extending below bottom of webbing.
    Step 2: Fold that 20mm tab up onto the BACK face.
    Step 3: Fold overlaps Strip B's bottom end → electrical short circuit.
    Step 4: Clamp or tape fold with copper tape pieces.
    Step 5: For VHF/UHF: solder the fold for reliable contact.


5. FEED POINT CONNECTOR DETAIL (HF PORTABLE)
===============================================

   FRONT FACE (Strip A):              BACK FACE (Strip B):

   │ ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ │        │ ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ │
   │         ┌──────────┐   │        │   ┌──────────┐         │
   │         │ CLIP A   │─CENTER── ──┤   │  CLIP B  │───SHIELD │
   │         │(insulate │   │        │   │(insulate │         │
   │         └──────────┘   │        │   └──────────┘         │
   │ ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ │        │ ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ │
   └─────────────────────────┘        └─────────────────────────┘

   Both clips at SAME HEIGHT = d_feed from bottom.
   Both clips on INSULATED jaw to avoid shorting to webbing frame.
   Use spring-loaded camera battery clips or modified alligator clips.

   SLIDE BOTH CLIPS UP/DOWN TOGETHER to find minimum SWR.


6. FEED POINT CONNECTOR DETAIL (VHF/UHF SOLDERED)
====================================================

   Prepare a 25mm × 25mm copper strip bent into a U-shape:

            ←25mm→
         ┌────────────────────┐  TOP VIEW
    ┌────┤  CENTER CONDUCTOR  ├────┐
    │    └────────────────────┘    │
    │SHIELD    ← WEBBING →   SHIELD│
    │    ┌────────────────────┐    │
    └────┤   COAX SHIELD TAB  ├────┘
         └────────────────────┘

   INSTALLATION:
   1. At d_feed, cut 10mm notch in webbing to expose both face conductors.
   2. Solder center conductor tab to STRIP A (front face tape).
   3. Solder shield tab to STRIP B (back face tape).
   4. Fill notch with RTV silicone; let cure 4 hours.
   5. Route coax down the webbing; secure with cable tie every 30cm.
   6. Add ferrite choke (5 turns of coax on FT-240-43) at feed point.


7. ROLL-UP STORAGE
===================

    Step 1: Fold antenna in half lengthwise (fold webbing in half, long way)
    Step 2: Start rolling from TOP (open end) toward BOTTOM
    Step 3: When rolled, secure with two rubber bands or velcro strap
    Step 4: Clip feed connector inside roll

8. DEPLOYMENT — VERTICAL (PRIMARY)
====================================

            ┌─────────────────────────────────────┐
            │              TOP (open)              │
            │              ↕                       │
            │              MAST / POLE            │
            │              (support)               │
            │              ↕                       │
            │  ┌──────────────────────────────┐   │
            │  │  J-POLE WEBBING (vertical)   │   │
            │  │  hanging or tied to pole     │   │
            │  │                              │   │
            │  │ →← coax exits at feed point  │   │
            │  │    routed down mast          │   │
            │  │                              │   │
            │  │  BOTTOM = short circuit      │   │
            │  └──────────────────────────────┘   │
            │                                      │
            └─────────────────────────────────────┘
    Mount with top of antenna at λ/4 above ground minimum.
    For VHF/UHF: any height > 1m sufficient.
    For HF 40m: mount top at ≥ 10m for best low-angle radiation.


9. DEPLOYMENT — SLOPER (SPACE-SAVING)
=======================================

                     ROPE ──────────────→ tree/post (TOP support)
                    /
                   /  ← J-pole webbing at 30–60° angle
                  /
                 /   coax exits at feed point
                /    hangs vertically from feed tab
               /
    ═══════════ GROUND

    Sloper produces directive pattern toward the low end (away from the tall support).
    Best for point-to-point at HF.
    J-pole feed coax must clear the sloper wire; use ferrite choke at feed point.
