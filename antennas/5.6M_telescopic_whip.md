  Why 160m Cannot Share the Tapped Coil
                                                                                
  For alligator clip access, minimum 1/8" gap between turn edges is needed.
  Solving Wheeler for 148 μH with those constraints:                            
                  
  Wire:  #16 AWG bare copper  OD = 0.0508"                                      
  Gap:   0.125"                                                                 
  Pitch: 0.0508 + 0.125 = 0.1758"    TPI = 5.69                                 
                                                                                
  Quadratic: 0.9025n² − 63.62n − 1264.2 = 0   (for L=148)                       
                                                                                
  n = [244.3 + √(244.3² + 4 × 0.9025 × 1264.2)] / 1.805                         
    = [244.3 + √(59683 + 4563)] / 1.805                                       
    = [244.3 + 253.5] / 1.805                                                   
    = 276 turns,  l = 276/5.69 = 48.5"
                                                                                
  48.5 inches of coil for 160m — impractical. This is inescapable: the 148 μH → 
  36.2 μH inductance ratio is ~4:1, which drives coil length ~4:1 at fixed turn 
  spacing.                                                                      
                                                                              
  Solution: Two coils on the same form diameter:                              

  ┌─────────────┬─────────────────┬─────────────────────────────┐               
  │    Coil     │      Bands      │            Type             │
  ├─────────────┼─────────────────┼─────────────────────────────┤               
  │ Tapped coil │ 80m / 40m / 30m │ Spaced, alligator clip taps │
  ├─────────────┼─────────────────┼─────────────────────────────┤             
  │ 160m coil   │ 160m only       │ Close-wound, swap in/out    │               
  └─────────────┴─────────────────┴─────────────────────────────┘               
                                                                                
  ---                                                                           
  Coil Design — Wheeler's Formula                                             
                                                                                
  L (μH) = r²n² / (9r + 10l)
                                                                                
  r = coil radius (inches)                                                      
  l = winding length (inches)                                                   
  n = turns                                                                     
                                                                              
  For uniform spacing, l = n / TPI                                              
  
  Substituting l = n/TPI and solving for n:                                     
                  
  r²n² − (10L/TPI)n − 9Lr = 0    ← quadratic in n                               
                  
  n = [ (10L/TPI) + √((10L/TPI)² + 4r²·9Lr) ] / (2r²)                           
                  
  PVC form: 1.5" nominal Sch40, OD = 1.900", r = 0.950", r² = 0.9025            
                  
  ---                                                                           
  Coil A — Tapped Coil (30m / 40m / 80m)
                                                                                
  Wire: #16 AWG bare copper — stiff (holds spacing), alligator clips grip bare
  copper without piercing enamel                                                
  Gap between turns: 1/8" = 0.125" (3.2 mm) — any alligator clip fits
  Wire OD: 0.0508"                                                              
  Turn pitch: 0.0508 + 0.125 = 0.1758" → TPI = 5.69                             
                                                                                
  ---                                                                           
  Full Coil — 80m (36.2 μH)                                                   
                                                                                
  a = r² = 0.9025 
  b = −10L/TPI = −10 × 36.2 / 5.69 = −63.62                                     
  c = −9Lr = −9 × 36.2 × 0.950 = −309.3
                                                                                
  0.9025n² − 63.62n − 309.3 = 0                                                 
                                                                                
  n = [ 63.62 + √(63.62² + 4 × 0.9025 × 309.3) ] / (2 × 0.9025)                 
    = [ 63.62 + √(4048 + 1116) ] / 1.805                                      
    = [ 63.62 + √5164 ] / 1.805                                                 
    = [ 63.62 + 71.86 ] / 1.805                                                 
    = 135.48 / 1.805                                                          
    = 75.1 → 75 turns                                                           
                                                                                
  l = 75 / 5.69 = 13.18"                                                      
                                                                                
  Verify: L = (0.9025 × 75²) / (9×0.950 + 10×13.18)                             
             = (0.9025 × 5625) / (8.55 + 131.8)                               
             = 5077 / 140.35                                                    
             = 36.2 μH ✓
                                                                                
  Wire needed: 75 × π × (1.900 + 0.0508)" = 75 × π × 1.951" = 459" ≈ 38.3 ft    
                                                                              
  ---                                                                           
  40m Tap (8.0 μH)
                                                                              
  Same pitch, solve for n₁ turns from the feed end:
                                                                                
  0.9025n₁² − 14.06n₁ − 68.4 = 0
                                                                                
  n₁ = [ 14.06 + √(14.06² + 4 × 0.9025 × 68.4) ] / 1.805                        
     = [ 14.06 + √(197.7 + 247.0) ] / 1.805                                     
     = [ 14.06 + √444.7 ] / 1.805                                               
     = [ 14.06 + 21.09 ] / 1.805                                                
     = 19.5   →   straddles turns 19 and 20                                   
                                                                                
  Turn 19: l = 19 × 0.1758 = 3.340"                                             
           L = (0.9025 × 361) / (8.55 + 33.40) = 325.8 / 41.95 = 7.77 μH        
  (−2.8%)                                                                       
                                                                              
  Turn 20: l = 20 × 0.1758 = 3.516"                                             
           L = (0.9025 × 400) / (8.55 + 35.16) = 361.0 / 43.71 = 8.26 μH
  (+3.3%)                                                                       
  
  Clip at turn 20 (8.26 μH); retract whip ~4 cm to compensate. Or clip turn 19  
  and extend whip ~4 cm.
                                                                                
  ---             
  30m Tap (2.52 μH)                                                           

  0.9025n₂² − 4.429n₂ − 21.55 = 0
                                                                                
  n₂ = [ 4.429 + √(4.429² + 4 × 0.9025 × 21.55) ] / 1.805                       
     = [ 4.429 + √(19.62 + 77.81) ] / 1.805                                     
     = [ 4.429 + √97.43 ] / 1.805                                               
     = [ 4.429 + 9.871 ] / 1.805                                              
     = 7.92  →  turn 8

          L = (0.9025 × 64) / (8.55 + 14.06)                                    
            = 57.76 / 22.61                                                     
            = 2.55 μH  (+1.2%) ✓                                              
                                                                                
  Clip at turn 8 — essentially exact, no adjustment needed.

Can the two coils be made so they can be stacked 

Yes — cleanly, with a calculated inductance split and a bypass jumper for band
   selection.                                                                   
                                                                                
  ---
  Concept                                                                       
         
  The 160m coil and tapped 80m-30m coil go on the same PVC pipe, separated by a 
  short plain section to minimize mutual coupling. A bypass jumper shorts out   
  the bottom section for all bands except 160m.                               
                                                                                
          ↑ Whip  
  ┌───────┤ Turn 75  (80m, full)                                                
  │  ···  │                                                                     
  ├───────┤ Turn 20  (40m)                                                      
  ├───────┤ Turn 8   (30m)                                                      
  │  ···  │                                                                   
  └───────┘ Top coil — #16 AWG bare, spaced    13.2"                            
            ───────── 3-4" plain PVC gap ────────────                           
  ┌───────┐ Bottom coil — #22 AWG close-wound   1.46"                           
  └───────┘                                                                     
          ↓ Feed                                                                
                                                                                
  Bypass jumper clips across the bottom coil terminals. Present for 30m/40m/80m.
   Removed for 160m.                                                          
                                                                                
  ---             
  Bottom Coil Calculation                                                     
                         
  The bottom coil supplies whatever inductance the top coil lacks for 160m:
                                                                                
  L_bottom = L_total − L_top(full)
           = 148.0 − 36.2                                                       
           = 111.8 μH   (ignoring mutual coupling — corrected below)            
                                                                              
  Mutual coupling correction: Both coils share the same axis. With 3-4"         
  separation on a 1.9" diameter form, the coupling coefficient k ≈ 0.05. Since
  both coils are wound the same rotational direction the fields aid:            
                  
  M = k × √(L_bottom × L_top)                                                 
    = 0.05 × √(106 × 36.2)
    = 0.05 × 61.9                                                               
    = 3.1 μH
                                                                                
  2M ≈ 6 μH added to series total                                               
                                                                              
  So the bottom coil target drops to:                                           
                  
  L_bottom = 148 − 36.2 − 6 = 105.8 μH                                          
                  
  Solve Wheeler for 105.8 μH, #22 AWG close-wound (TPI = 35.7), r = 0.950":     
  
  0.9025n² − 29.65n − 904.6 = 0                                                 
                  
  n = [ 29.65 + √(29.65² + 4 × 0.9025 × 904.6) ] / 1.805                        
    = [ 29.65 + √(879.1 + 3265.2) ] / 1.805
    = [ 29.65 + √4144.3 ] / 1.805                                               
    = [ 29.65 + 64.38 ] / 1.805
    = 52.1  →  52 turns                                                         
                  
  l = 52 / 35.7 = 1.46"                                                         
                  
  Verify: L = (0.9025 × 2704) / (8.55 + 14.57)                                  
             = 2440 / 23.12
             = 105.5 μH                                                         
                  
  Series total: 105.5 + 36.2 + 6.0 (2M) = 147.7 μH ≈ 148 μH ✓                   
  
  Wire needed: 52 × π × 1.928" = 315" ≈ 26.3 ft of #22 AWG enameled             
                  
  ---                                                                           
  Complete Coil Spec
                                                                                
  ┌─────────────────┬─────────────────────────┬───────┬────────┬────────────┐ 
  │     Section     │          Wire           │ Turns │ Length │ Inductance │   
  ├─────────────────┼─────────────────────────┼───────┼────────┼────────────┤

  ├──────┼─────────────────────────┼───────────────────────────────┤

  ---                                                                           
  Winding Direction
                                                                                
  Wind both coils in the same rotational direction when viewed from the whip end
   — this ensures the fields aid in series (adds mutual inductance as accounted 
  for above). Reversing one coil would subtract 2M and put you ~12 μH short on
  160m.                                                                         
                  
  ---                                                                         
  Tuning After Assembly
                       
  k = 0.05 is an estimate. After assembly:
                                                                                
  1. Use an antenna analyzer or dip meter across the coil system                
  2. Check 160m resonance (should be close to 1.9 MHz with full whip)           
  3. If too high (over-inductive): remove 1 turn at a time from the bottom coil 
  4. If too low (under-inductive): add turns to the bottom coil                 
  5. All other bands tune via whip extension only — the top coil taps stay fixe

Loading Coil Calculations: 5.6m Telescopic Whip on 1.5" PVC                   
                                                                                
  ---                                                                           
  Parameters & Assumptions
                                                                                
  - Whip: h = 5.6m, avg effective radius a ≈ 6mm (typical telescoping sections)
  - Configuration: Base-loaded vertical monopole over ground plane              
  - PVC form: 1.5" nominal Sch40, OD = 1.900", coil radius r = 0.950"
  - Formula set: Wheeler single-layer solenoid + transmission-line monopole     
  model                                                                         
                                                                                
  ---                                                                           
  Step 1 — Whip Characteristic Impedance                                      
                                                                                
  Z₀ = 60 × [ln(2h/a) − 1]
     = 60 × [ln(2 × 5.6 / 0.006) − 1]                                           
     = 60 × [ln(1867) − 1]                                                      
     = 60 × [7.533 − 1]                                                         
     = 60 × 6.533                                                               
     ≈ 392 Ω  (use 400 Ω)                                                       
                                                                                
  ---                                                                         
  Step 2 — Electrical Length & Required Reactance                               
                                                 
  The short whip presents capacitive reactance at the feed:                   
                                                                                
  θ = kh = (2π / λ) × 5.6m
                                                                                
  X_antenna = −Z₀ × cot(θ)          [negative = capacitive]                     
  X_coil_needed = +Z₀ × cot(θ)      [loading coil cancels this]                 
                                                                                
  Required inductance: L = X_L / (2πf)                                        
                                                                                
  ┌──────┬────────────┬───────┬───────┬────────┬───────────┬────────────┐       
  │ Band │  Center f  │ λ (m) │ θ (°) │ cot(θ) │ X_ant (Ω) │ L_req (μH) │     
  ├──────┼────────────┼───────┼───────┼────────┼───────────┼────────────┤       
  │ 160m │ 1.900 MHz  │ 157.9 │ 12.8° │ 4.409  │ −1764     │ 147.7      │
  ├──────┼────────────┼───────┼───────┼────────┼───────────┼────────────┤

  inductive reactance — no loading coil needed. Retract to 5.3m for resonance,

  ---                                                                         
  Step 3 — Coil Winding via Wheeler's Formula

  Wheeler (single-layer solenoid):
      L (μH) = r²n² / (9r + 10l)                                                
                                                                                
      r = coil radius (inches)                                                  
      l = winding length (inches)                                               
      n = number of turns                                                       
                                                                              
  For close-wound coil, l = n / TPI, substituting gives quadratic:              
      r²n² − (10L / TPI)n − 9Lr = 0
                                                                                
      n = [ (10L/TPI) + √((10L/TPI)² + 36Lr·r²·TPI²/TPI²) ] / 2r²               
                                                                                
  Simplified:                                                                   
      n = [ (10L/TPI) + √((10L/TPI)² + 4r²·9Lr) ] / (2r²)                     
                                                                                
  Wire gauge specs (enameled copper):

  │ AWG │ Bare dia (in) │ With enamel (in) │ TPI  │                           
  ├─────┼───────────────┼──────────────────┼──────┤                             
  │ #22 │ 0.0253        │ 0.0280           │ 35.7 │
  ├─────┼───────────────┼──────────────────┼──────┤                           
  │ #20 │ 0.0320        │ 0.0350           │ 28.6 │                             
  ├─────┼───────────────┼──────────────────┼──────┤                             
  │ #18 │ 0.0403        │ 0.0435           │ 23.0 │                             
  └─────┴───────────────┴──────────────────┴──────┘

  Practical Notes                                                             
                 
  Ground system: These figures assume a good RF ground. Minimum 4 quarter-wave
  radials laid on the ground, or 8 for 160m where you need every dB. Vehicle    
  body works for mobile.
                                                                                
  Coil Q: PVC dielectric loss degrades Q vs. air-wound. Silver-plated wire on   
  1.5" PVC gets you Q ≈ 150–250 depending on band. To push Q > 300, air-wind and
   use a polypropylene spacer coil form.                                        
                  
  Tuning procedure: Install coil, extend whip fully, sweep with antenna         
  analyzer. Adjust whip extension to hit resonance — the telescoping element is
  your fine-tune knob.                                                          
                  
  Input impedance matching: R_in = R_rad at resonance. 2 Ω at 160m and 8 Ω at   
  80m are well below 50 Ω — you need an ATU or a gamma/L-network for efficient
  power transfer on those bands.                                                
                  
  Tapped coil option: Wind the 160m coil (67T) with clip leads to taps. For a   
  single-form tapped design, the tap points differ from the standalone coil
  counts because winding pitch is fixed: 80m tap ≈ turn 25 (not 27), 40m tap ≈  
  turn 12, 30m tap ≈ turn 6. Stray capacitance between sections degrades Q on
  30m/40m.

how do I to tune a 5.6M telescopic whip for 17M, 15M, 12M, 10M, 6M

Tuning a 5.6m Whip on 17m Through 6m                                                 
                                                            
  This is the opposite problem from the lower bands. Instead of the whip being too     
  short and needing a loading coil, on these bands the whip is too long — it's past λ/4
   and presents an inductive (or very high) impedance at the base.                     
                                                            
  ---                                                                                
  Electrical Length — Full 5.6m Whip
                                    
  βh (degrees) = 6.720 × f_MHz      (for h = 5.6m, c = 300 m/s)
  X_ant = −Z₀ / tan(βh)             Z₀ = 403Ω                                          
                                                                                       
  ┌──────┬─────────┬────────┬───────────────────────┬──────────────┬───────────┐       
  │ Band │ f (MHz) │ βh (°) │       Condition       │  X_ant (Ω)   │ R_in (Ω)  │       
  ├──────┼─────────┼────────┼───────────────────────┼──────────────┼───────────┤       
  │ 17m  │ 18.068  │ 121.4° │ 1.35 × λ/4            │ +233 (ind.)  │ ~62       │     
  ├──────┼─────────┼────────┼───────────────────────┼──────────────┼───────────┤     
  │ 15m  │ 21.225  │ 142.6° │ 1.58 × λ/4            │ +526 (ind.)  │ ~90       │       
  ├──────┼─────────┼────────┼───────────────────────┼──────────────┼───────────┤       
  │ 12m  │ 24.940  │ 167.6° │ 1.86 × λ/4 → near λ/2 │ +1830 (ind.) │ ~400      │       
  ├──────┼─────────┼────────┼───────────────────────┼──────────────┼───────────┤       
  │ 10m  │ 28.500  │ 191.5° │ just past λ/2         │ −1980 (cap.) │ very high │     
  ├──────┼─────────┼────────┼───────────────────────┼──────────────┼───────────┤       
  │ 6m   │ 50.125  │ 336.8° │ 0.94 × λ              │ +940 (ind.)  │ ~300      │
  └──────┴─────────┴────────┴───────────────────────┴──────────────┴───────────┘       
                                                            
  12m and 10m are near the λ/2 anti-resonance (180°) where input impedance             
  theoretically approaches infinity. Using the full 5.6m whip on these bands is not
  practical.                                                                           
                                                            
  ---                                                                                
  Primary Solution: Collapse Whip to λ/4
                                                                                       
  The cleanest approach on all five bands. No components needed, SWR ≈ 1.4:1 directly
  on 50Ω coax.                                                                         
                                                            
  λ/4 resonant length = 71.5 / f_MHz   (meters, includes ~5% end-effect shortening)

  ├──────┼─────────┼────────────┼─────────────┼──────────────┤

  ├──────┼─────────┼────────────┼─────────────┼──────────────┤

  ├──────┼─────────┼────────────┼─────────────┼──────────────┤

  └──────┴─────────┴────────────┴─────────────┴──────────────┘                         
  
  These are starting lengths — trim for minimum SWR with NanoVNA or SWR meter.         
                                                            
  ---                                                                                  
  17m — Series Capacitor Alternative (Full Whip)            
                                                                                       
  17m is a special case. At βh = 121.4°, the input resistance of the full 5.6m whip
  happens to be close to 50Ω (~62Ω). A single series capacitor to cancel the inductive 
  reactance gives a near-perfect match — no whip adjustment needed.
                                                                                       
  X_ant = −Z₀/tan(121.4°) = −403/(−1.629) = +233Ω           
  C_series = 1/(2π × 18.068×10⁶ × 233) = 37.8 pF                                       
                                                                                       
  At resonance: Z_feed ≈ 62 + j0Ω → SWR ≈ 62/50 = 1.24:1                               
                                                                                       
  A 33–39 pF silver mica or NP0 capacitor in series at the whip base. Adjust value for 
  minimum SWR. This configuration works well for portable or mobile operation where  
  keeping the whip extended to full length is convenient.                              
                                                            
  This does not work for 15m — the required capacitor is 14 pF (stray capacitance      
  territory) and R_in ≈ 90Ω still needs a shunt match.
                                                                                       
  ---                                                       
  6m — Three Options                                                                 
                    
  The 5.6m whip is 94% of a full wavelength on 6m — near the λ anti-resonance. Do not
  use the full extension.                                                              
  
  Option A — λ/4 at 1.43m (simplest):                                                  
  h = 71.5/50.125 = 1.43m                                   
  R_in ≈ 36Ω, SWR ≈ 1.4:1                                                            
  Collapse all sections except the base section and part of the next. Clean, no        
  matching needed.                                                                     
                                                                                       
  Option B — 3λ/4 at 4.49m (slight gain, needs matching):                              
  h = 3 × 71.5/50.125 = 4.28m   (field-trim upward from 4.0m)                          
  R_in ≈ 100–150Ω, X_in ≈ small                                                      
  SWR ≈ 3:1 → needs L-network (shunt capacitor + series inductor)                      
  The 3λ/4 monopole has a slightly lower radiation angle than λ/4, useful for DX.      
  Requires an ATU or fixed L-network at the base.                                      
                                                                                       
  Option C — 5/8λ at 3.74m (mobile standard, needs matching):                          
  h = 5 × 71.5/(8 × 50.125) = 3.56m                                                    
  R_in ≈ 50Ω, X_in ≈ +30Ω (small inductive)                                          
  Series C ≈ 106 pF, then SWR ≈ 1.0:1                                                  
  The 5/8λ monopole presents near-50Ω resistance after resonating with a small series  
  capacitor. Most 6m mobile antennas use this approach.                                
                                                                                       
  ---                                                                                  
  Field Procedure                                                                      
                                                                                     
  1. Calculate starting lengths (from table above)                                   
                                                                                       
  2. Mark the whip — Use small wraps of colored electrical tape at each band's         
  retraction point:                                                                    
  Suggested color code:                                                                
    17m — red     (3.95m from tip)                                                   
    15m — orange  (3.37m from tip)                                                     
    12m — yellow  (2.87m from tip)
    10m — green   (2.51m from tip)                                                     
    6m  — blue    (1.43m from tip)                          
  Measure from the tip downward so marks stay consistent regardless of how sections    
  nest.                                                                                
                                                                                       
  3. Fine-tune with NanoVNA:                                                           
  - Port 1 → coax → whip base (good ground plane underneath)                           
  - Sweep ±500 kHz around band center                                                  
  - Find minimum S11 frequency                                                       
  - If resonance is below your target: collapse whip slightly (shorter → higher        
  frequency)                                                                   
  - If resonance is above target: extend slightly                                      
                                                            
  4. Mark final lengths — Sharpie mark on the innermost extended section at the collar.

  Efficiency on These Bands
                                                                                       
  Unlike 160m and 80m where coil loss dominated, on 17m–6m the trimmed whip has:
  - No loading coil → no coil loss

  The whip is one terminal of the antenna. The counterpoise is the other. Ground     
  resistance R_ground adds directly to the loss budget:
                                                                                     
  Efficiency = R_rad / (R_rad + R_coil + R_ground)          
                                                                                     
  At 160m, R_rad is only 2Ω — R_ground dominates everything. Counterpoise quality    
  matters more on the low bands.

  20m / 30m / 40m — Full resonant radials

  whip — not going to be good regardless. Deploy the 80m radials and accept it.

  field station use. Wind on a dedicated spool.

  Use a 10m wire with a series loading coil (same concept as the whip — resonate a
  short wire at 1.9 MHz). Adds complexity but keeps the kit compact.

  ---                                                                                
  RF on the Coax Shield                                                            
                                                                                     
  Without a counterpoise, the coax shield becomes the counterpoise by default — RF
  current flows back down the outside of the coax and into the rig. This causes:     
  - RF in the shack / RF burns
  - TVI/RFI to nearby equipment                                                      
  - Variable SWR depending on coax routing                  
  - Pattern distortion                                                               
                                                                                     
  Fix: Wind 8–10 turns of coax at the feed point on a 3" diameter ferrite or PVC     
  form. This choke (air-core or ferrite) presents 500Ω+ reactance to common-mode     
  current at HF and forces current into the counterpoise wires instead of down the 
  coax. Critical for field use where the coax lies on the ground with the radials.

how do i measure R_ground

What You're Actually Measuring                                                     
                                         
  At resonance (X = 0), the antenna feed impedance is purely resistive:              
                                                                                     
  Z_feed = R_rad + R_coil + R_ground                                                 
                                                            
  Measure Z_feed, subtract the calculated R_rad and R_coil, what remains is R_ground.
   Everything is in series so the arithmetic is straightforward — the hard part is
  accurate impedance measurement at low values.                                      
                                                            
  ---
  Method 1 — NanoVNA at the Feed Point (Primary)
                                                                                     
  Calibration Plane
                                                                                     
  The NanoVNA must be calibrated at the antenna base, not at the end of a long       
  feedline. Use a short pigtail (< 15cm) from the NanoVNA port to the feed point, and
   perform SOL cal there.                                                            
                                                            
  NanoVNA ── short pigtail (15cm max) ── feed point
                                              │
                                      loading coil                                   
                                              │
                                            whip                                     
                                      coax shield ── radials
                                                                                     
  Procedure
                                                                                     
  1. Install the counterpoise configuration under test                               
  2. Connect NanoVNA to feed point, short pigtail, SOL calibrated at that plane
  3. Sweep across the band (e.g., 6.9–7.5 MHz for 40m)                               
  4. Find resonance — where the reactance (X) crosses zero                           
  5. Read R at that frequency                                                        
  6. R_ground = R_measured − R_rad − R_coil                                          
                                                                                     
  Reference Values (to validate your measurements)          

  These are targets based on the earlier calculations. If your measurement is wildly 
  different, check calibration plane and connections.

  │ Band │ R_rad │   R_coil     │ Expected R_total (1   │  Expected R_total (4   │
  │      │       │   (Q=200)    │        radial)        │        radials)        │   
  ├──────┼───────┼──────────────┼───────────────────────┼────────────────────────┤

  ---                                                                                
  Method 2 — SWR Meter (Any Transmitter + SWR Bridge)       
                                                                                     
  At resonance (X = 0), SWR depends only on R_feed relative to 50Ω:
                                                                                     
  If R_feed < 50Ω:    R_feed = 50 / SWR                     
  If R_feed > 50Ω:    R_feed = 50 × SWR                                              
                                                            
  For all bands in this project, R_feed < 50Ω, so:                                   
                                                            
  R_ground = (50 / SWR) − R_rad − R_coil                                             
                                                                                     
  ⚠ The SWR Paradox — Important                                                      
                                                                                     
  Lower SWR at resonance does NOT mean a better antenna. With a short loaded whip,   
  more ground loss actually makes SWR look better:          
                                                                                     
  ┌──────────────────┬─────────────────┬─────────┬───────┬────────────┐              
  │   Counterpoise   │ R_ground (160m) │ R_total │  SWR  │ Efficiency │
  ├──────────────────┼─────────────────┼─────────┼───────┼────────────┤              
  │ 4× λ/4 radials   │ 5Ω              │ 15.8Ω   │ 3.2:1 │ 12.7%      │
  ├──────────────────┼─────────────────┼─────────┼───────┼────────────┤
  │ 1× λ/4 radial    │ 15Ω             │ 25.8Ω   │ 1.9:1 │ 7.7%       │              
  ├──────────────────┼─────────────────┼─────────┼───────┼────────────┤              
  │ Bare coax shield │ ~100Ω           │ ~110Ω   │ 2.2:1 │ 1.8%       │              
  └──────────────────┴─────────────────┴─────────┴───────┴────────────┘              
                                                            
  The most efficient configuration (4 radials) shows the worst SWR. A 3:1 SWR reading
   on a short loaded vertical is a good sign — it means R_feed is low, which means
  ground losses are low relative to R_rad.                                           
                                                            
  ---
  Method 3 — Measure Coil Q First (Needed for Accurate R_ground)
                                                                
  The R_coil estimate (X_L/Q with Q=200 assumed) can be wrong by ±50%. Measure it
  directly before trusting the R_ground extraction.                                  
   
  Procedure                                                                          
                                                            
  1. Connect the loading coil to NanoVNA via the same short pigtail                  
  2. Add a known capacitor C across the coil to form a resonant circuit
    - Choose C so resonance falls in the operating band                              
    - Example, 40m coil (L = 8μH): C = 1/(4π²f²L) = 1/(4π²×7.15e6²×8e-6) = 62pF      
  3. Sweep through resonance                                                         
  4. Read the −3dB bandwidth (BW) of the resonance peak in S11                       
  5. Q = f₀ / BW                                                                     
  6. R_coil = X_L / Q = (2πf₀L) / Q                                                  
                                                                                     
  Typical Expected Values                                                            
                                                            
  ┌──────┬─────────┬───────┬───────────────────────┬─────────────────┐

  ├──────┼─────────┼───────┼───────────────────────┼─────────────────┤

  If Q is lower than 100 on 160m, the coil winding has problems — recheck for shorts

  ---                                                       
  Method 4 — Low-Z Accuracy Improvement (λ/4 Transformer)
                                                         
  The NanoVNA reads low impedances (< 15Ω) with degraded accuracy. Use a quarter-wave
   coax transformer at the measurement frequency to multiply the antenna impedance   
  into a readable range:
                                                                                     
  Z_NanoVNA = Z₀² / Z_antenna     (valid only at λ/4 frequency)
                                                                                     
  Z_antenna = 2500 / Z_NanoVNA    (for 50Ω coax, Z₀² = 2500)                         
                                                                                     
  Physical λ/4 Lengths (50Ω coax, VF = 0.66 for RG-58)                               
                                                            
  ┌──────┬────────────────┬──────────────────────┐                                   
  │ Band │ Free-space λ/4 │ Physical coax length │          
  ├──────┼────────────────┼──────────────────────┤                                   
  │ 160m │ 39.5m          │ 26.1m of RG-58       │          
  ├──────┼────────────────┼──────────────────────┤
  │ 80m  │ 20.0m          │ 13.2m                │                                   
  ├──────┼────────────────┼──────────────────────┤
  │ 40m  │ 10.5m          │ 6.9m                 │                                   
  ├──────┼────────────────┼──────────────────────┤                                   
  │ 30m  │ 7.4m           │ 4.9m                 │
  ├──────┼────────────────┼──────────────────────┤                                   
  │ 20m  │ 5.3m           │ 3.5m                 │          
  └──────┴────────────────┴──────────────────────┘

  Example: 40m antenna with R_total ≈ 27Ω. Through 6.9m of RG-58:                    
  Z_NanoVNA = 2500/27 = 92.6Ω — well within NanoVNA's accurate range.
  Read 92.6Ω on NanoVNA → actual antenna Z = 2500/92.6 = 27Ω ✓                       
                                                                                     
  40m and 30m pieces are field-portable. The 160m 26m length is a drawback but could 
  be left connected permanently during the field test session.

  Method 5 — Field Strength Comparison (TinySA)
                                               
  Not for absolute R_ground but for confirming which counterpoise configuration is
  actually working. Place TinySA with a short whip or wire as receive antenna at a   
  fixed distance (50–100m):
                                                                                     
  Transmit at constant power (uSDX at minimum, ~0.5W QRP)   
  Fix frequency exactly on band center                                               
  Record TinySA level reading for each configuration
                                                                                     
  ┌───────────────────────────┬────────────────────────────────┐                     
  │   Configuration change    │   Expected ΔdBm at receiver    │                     
  ├───────────────────────────┼────────────────────────────────┤                     
  │ 1 → 4 radials (160m)      │ +0.5 to +1.5 dB                │
  ├───────────────────────────┼────────────────────────────────┤
  │ 1 → 4 radials (40m)       │ +1.4 to +2.4 dB                │                     
  ├───────────────────────────┼────────────────────────────────┤

  The field strength differences are modest between radial counts but dramatic       
  between no counterpoise and one good radial. The TinySA can resolve 0.5dB reliably.

  Practical Workflow for This Project

  For each band:
                                                                                     
  1. Measure coil Q → get accurate R_coil
     (do once, doesn't change)                                                       
                                                                                     
  2. Install antenna + one λ/4 radial                                                
     → NanoVNA sweep → find resonance → read R₁                                      
     → R_ground_1 = R₁ − R_rad − R_coil                                              
     → Record SWR at resonance                              
                                                                                     
  3. Add 3 more λ/4 radials (4 total)                                                
     → NanoVNA sweep → read R₄
     → R_ground_4 = R₄ − R_rad − R_coil                                              
     → Note: R₄ < R₁, SWR will be HIGHER than with 1 radial                          
                                                                                     
  4. TinySA field check at 50m                                                       
     → Confirm signal improvement matches calculation                                
                                                                                     
  5. Log results:
     Band / R_ground_1 / R_ground_4 / Efficiency_1 / Efficiency_4                    
                                                                                     
  This gives you a complete characterization of the ground at each test site —       
  directly useful for Merv's field propagation research since ground conductivity    
  varies significantly between the Merced valley floor, rocky ridgelines, and        
  seasonal wet/dry conditions.
