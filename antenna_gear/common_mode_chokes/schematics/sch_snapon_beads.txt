SNAP-ON BEAD THEORY
───────────────────
Snap-on ferrite cores (also called clamshell cores or split ferrites) clamp
around existing cables without cutting connectors.  A single snap-on bead on
a coax cable provides 100–500 Ω of common-mode impedance.  For adequate
choking (>1000 Ω), multiple beads must be stacked in series.

Each additional bead adds impedance in series (not parallel):
  Z_total = N_beads × Z_single_bead   (approximation; mutual coupling minor)

Stacking vs. multiple passes:
  Threading cable through same bead N times: Z × N² (inductive, adds as N-turn coil)
  N separate beads, 1 pass each: Z × N (resistive + inductive, more broadband)

For broadband suppression: multiple beads preferred
For single-frequency (powerline noise): multiple turns preferred

SCHEMATIC — SNAP-ON BEAD INSTALLATION
================================================================================

COAX LINE (end view, snap-on beads clamped around outer jacket):

  ───────────────────────────────────────────────────────────── coax outer jacket
                │       │       │       │       │       │
              [B1]    [B2]    [B3]    [B4]    [B5]    [B6]     snap-on beads
                │       │       │       │       │       │
  ───────────────────────────────────────────────────────────── coax outer jacket

  Bead spacing: 2–5mm between beads (touching OK; small gap prevents stress)
  Total length of 6-bead stack: ~200mm on RG-8X (32mm per bead × 6)
  Secure stack with cable ties or self-amalgamating tape wrap

MULTIPLE PASS (N-TURN EQUIVALENT) — FOR POWERLINE / MAINS CABLES:

  CABLE enters bead, loops back, passes through again N times:

  cable in ──► [BEAD aperture pass 1] ──loop──► [aperture pass 2] ──loop──► exit

  Impedance scales as N² (inductive behavior):
    1 pass:   |Z| = 270 Ω @ 1 MHz (Type 1, Mix 31)
    2 passes: |Z| ≈ 4 × 270 = 1080 Ω @ 1 MHz
    3 passes: |Z| ≈ 9 × 270 = 2430 Ω @ 1 MHz
    4 passes: |Z| ≈ 16 × 270 = 4320 Ω @ 1 MHz

  CAUTION: multiple passes resonant frequency shifts DOWN.  High-frequency
  performance degrades faster than single-pass multi-bead approach.
  Use multiple-pass for troublesome LF (AM broadcast, powerline) interference.
  Use series single-pass beads for broadband HF/VHF suppression.

SNAP-ON BEAD INSTALLATION GUIDE
================================================================================

INSTALLATION ON COAXIAL CABLE:
  1. Clean cable jacket with isopropyl alcohol; remove any grit.
  2. Mark bead positions (2–5mm spacing recommended).
  3. Snap bead open; lay cable in lower half groove.
  4. Snap closed; confirm secure closure (no gap at seam).
  5. Verify cable jacket not pinched at bead edges.
  6. Secure with 2-inch cable tie or tape wrap if beads will be moved.

INSTALLATION ON POWER/ETHERNET/USB CABLES:
  Same procedure.  For small cables (USB), fold cable once before inserting
  to increase effective turns (fold = 2 passes):
    USB cable folded once through Mix 31 bead: |Z| ≈ 4 × 270 = 1080 Ω @ 1 MHz

POSITION ON FEEDLINE:
  - Feedline snap-on beads: install at entry point to shack (at bulkhead).
  - Equipment supply cable: install at equipment power inlet.
  - Monitor/display cables: install at display end (where entering equipment).
  - Ferrite beads do NOT need to be installed at antenna feedpoint for filtering
    of common-mode currents entering the shack — shack entry is correct location.
  - For antenna feedpoint balun action: use wound toroid (sch_toroid_choke_hf.txt)
