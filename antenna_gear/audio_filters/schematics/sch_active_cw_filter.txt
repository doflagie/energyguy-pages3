SCHEMATIC: Active Op-Amp CW Audio Bandpass Filter
TM-AF-001  Rev A
CW Bandpass: 400–800 Hz center freq (switchable), Q = 5–25 variable
State-Variable Filter topology; NE5532 dual op-amp
================================================================================

THEORY — STATE VARIABLE FILTER (SVF)
──────────────────────────────────────
The SVF (Kerwin-Huelsman-Newcomb) uses three op-amps:
  U1A — summing amplifier (virtual ground summing node)
  U1B — first integrator  (produces −90° bandpass output)
  U2A — second integrator (produces −180° lowpass output)
  HP output = −(input + BP + LP feedbacks)
  Notch = LP + HP outputs

Transfer functions (with unity gain integrators):
  BP(s) = −(ω₀/Q) × s  /  (s² + (ω₀/Q)s + ω₀²)
  LP(s) =  ω₀²          /  (s² + (ω₀/Q)s + ω₀²)
  HP(s) = −s²            /  (s² + (ω₀/Q)s + ω₀²)

Parameters:
  ω₀ = 1/(R_INT × C_INT)       — integrator time constant sets center freq
  Q  = R_Q / R_FB               — ratio of Q resistors (see schematic)
  H₀ = −R2/R1                   — passband gain at center frequency

Frequency selection (C_INT switched, R_INT = 10 kΩ fixed):
  f₀ = 1 / (2π × R_INT × C_INT)
  400 Hz: C = 1/(2π × 10k × 400) = 39.8 nF → 39 nF
  500 Hz: C = 31.8 nF → 33 nF
  600 Hz: C = 26.5 nF → 27 nF
  700 Hz: C = 22.7 nF → 22 nF
  800 Hz: C = 19.9 nF → 18 nF (or 20 nF)

Q selection (R_Q variable, R_FB = 10 kΩ fixed):
  Q = R_Q / R_FB; for Q=5 to 25, R_Q = 50 kΩ to 250 kΩ
  Use 250 kΩ linear pot: R_Q = 50k–250k → Q = 5–25
  Corresponding −3 dB bandwidth at 700 Hz center:
    Q=5:  BW = 700/5  = 140 Hz   (wide CW or digital modes)
    Q=10: BW = 700/10 =  70 Hz   (standard CW)
    Q=15: BW = 700/15 =  47 Hz   (contest CW)
    Q=25: BW = 700/25 =  28 Hz   (extreme narrow; selectivity limited)

C_INT frequency select switch (SW1):
  Position 1 (400 Hz): C = 39 nF  (39n = 2× 22nF parallel − 5nF)
  Position 2 (500 Hz): C = 33 nF  (standard)
  Position 3 (600 Hz): C = 27 nF  (standard)
  Position 4 (700 Hz): C = 22 nF  (standard)
  Position 5 (800 Hz): C = 18 nF  (18nF = standard NP0)

Note: both integrators use the SAME switch bank (ganged).
Use a 2-pole 5-position rotary switch; SW1A for integrator 1, SW1B for integrator 2.

================================================================================
GAIN CALIBRATION
================================================================================

Passband gain at center frequency:
  H₀ = −R2/R1 = −10k/10k = −6 dB (unity with sign inversion)

For +6 dB gain: R2 = 20k
For  0 dB flat: R1 = R2 = 10k

Output level with typical radio (0 dBu = 600mV RMS audio):
  Output = Input − 1 dB insertion loss ≈ −1 dBu at passband center
  Note: SVF BP output is inverting; add unity inverter stage if polarity matters

  +9V ──┬── 10 µF electrolytic (−) to GND

  I_supply ≈ 2 × 8 mA = 16 mA total (±9V rails)
