================================================================================
SCHEMATIC: Variable Bandwidth Audio Filter with Switchable Q
TM-AF-001  Rev A
SSB/CW Combined — Selectable: 200 Hz / 500 Hz / 1500 Hz / 2700 Hz BW
Center Frequency Variable 300–3000 Hz; NE5532 op-amps
================================================================================

DESIGN APPROACH
───────────────
A 4th-order bandpass is built from two cascaded 2nd-order state-variable
biquad sections. The bandwidth is controlled by varying Q of each section
independently or together. Switched capacitor banks change center frequency.

Bandwidth modes (both sections same Q):
  Mode 1: BW = 200 Hz   → Q = f₀/BW (e.g., 700/200 = 3.5 per section)
  Mode 2: BW = 500 Hz   → Q = 700/500 = 1.4
  Mode 3: BW = 1500 Hz  → Q = 700/1500 = 0.47 (overdamped, loses peaking)
  Mode 4: BW = 2700 Hz  → Q = 0.26 (broad SSB mode)

For narrow modes, two cascaded biquads each with Q = √(desired_Q) gives
tighter 4th-order rolloff: −80 dB/decade vs −40 for 2nd-order.

Effective passband shape:
  Mode 1 (CW 200 Hz):  −80 dB/decade outside passband
  Mode 2 (CW 500 Hz):  −80 dB/decade
  Mode 3 (SSB 1500 Hz):−40 dB effective (broadband, single biquad behavior)
  Mode 4 (SSB 2700 Hz): flat response, filter acts as bandlimiting only

R_Q SWITCHING FOR BANDWIDTH CONTROL:

For fixed f₀ = 700 Hz (C_INT = 22 nF, R_INT = 10 kΩ):
  Q per section for 4th-order response:
    Mode 1 (200 Hz):  Q = 700/200 = 3.5 → R_Q = Q × R_LP = 3.5 × 10k = 35kΩ
    Mode 2 (500 Hz):  Q = 700/500 = 1.4 → R_Q = 14kΩ
    Mode 3 (1500 Hz): Q = 700/1500 = 0.47 → R_Q = 4.7kΩ
    Mode 4 (2700 Hz): Q = 700/2700 = 0.26 → R_Q = 2.6kΩ → use 2.7kΩ

SW_BW 4-position rotary switch selects R_Q:
  Pos 1: R_Q = 33kΩ  (≈ BW 200 Hz)
  Pos 2: R_Q = 15kΩ  (≈ BW 500 Hz)
  Pos 3: R_Q = 4.7kΩ (≈ BW 1500 Hz)
  Pos 4: R_Q = 2.7kΩ (≈ BW 2700 Hz)

================================================================================
CENTER FREQUENCY SELECTION
================================================================================

Both biquad sections share the SAME frequency-switch ganging.
4-pole 5-position rotary switch (SW_FREQ) controls all 4 C_INT capacitors
(2 integrators × 2 sections = 4 gangs):

  Freq   | C_INT  | Pole response (BW=500Hz mode)
  -------|--------|-------------------------------
  400 Hz | 39 nF  | 400 ± 250 Hz → 150–650 Hz
  500 Hz | 33 nF  | 500 ± 250 Hz → 250–750 Hz
  600 Hz | 27 nF  | 600 ± 250 Hz → 350–850 Hz
  700 Hz | 22 nF  | 700 ± 250 Hz → 450–950 Hz
  800 Hz | 18 nF  | 800 ± 250 Hz → 550–1050 Hz

SW_FREQ: 4P5T (4-pole 5-throw) — controls C1-INT in U1A integrator,
                                            C2-INT in U1B integrator,
                                            C3-INT in U2A integrator,
                                            C4-INT in U2B integrator

Alignment procedure:
  1. Set SW_FREQ to desired center frequency position
  2. Inject −10 dBu sine at center freq; note output = reference level (0 dB relative)
  3. Sweep through table above; record attenuation at each frequency
  4. Confirm −3 dB points match BW specification ±15%
  5. Record date, operator, serial number

================================================================================
INSERTION LOSS BUDGET
================================================================================

Each biquad adds ~0.5 dB passband insertion loss (op-amp noise, feedback loading)
Two cascaded sections: ~1.0 dB typical
Gain recovery: U3 output buffer with gain of 2 (6 dB) compensates loss

OUTPUT BUFFER (U3A, unity or ×2 gain):
         R_gain2 (10k or 20k for 0 or +6dB)
BP2 ──────────────────────────────┐
         R_gain1 (10k)             │
      ───/\/\/────────────────►────┤
      │                        ───┴───
     GND                      │ −    │──── OUT
                               │ U3A  │
                    Vmid ───── │ +    │
                                ───────

For ×2 gain: R_gain2 = 20kΩ
For ×1:      R_gain2 = 10kΩ
