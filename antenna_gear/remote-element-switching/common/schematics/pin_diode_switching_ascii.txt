================================================================================
BIAS VOLTAGE & CURRENT SPECIFICATIONS
================================================================================

    FORWARD BIAS (Element Active - Connected to Boom):
    ──────────────────────────────────────────────
    Applied Bias:     +12V (from 2N2222 collector rail)
    Forward Current:  10-20 mA (typical)
    Voltage Drop:     0.8-1.0V across PIN diode
    Series R Drop:    10-20mV across 1-2kΩ limit resistor

    Net 12V supply voltage for bias network: 12V
    After 1.5kΩ limit resistor at 10mA: ~12V - 15mV ≈ 11.985V applied to diode

    Series RFC Choke (47 nH) impedance at 432 MHz:
      Z_L = j*ω*L = j*2π*432e6 * 47e-9 = j128 Ω
    This is acceptable for DC bias (choke acts as short @ DC).


    REVERSE BIAS (Element OFF - Isolated):
    ──────────────────────────────────────────
    Applied Bias:     0V (GND) or -5V (optional for better isolation)
    Reverse Current:  < 1 µA (leakage, must stay negligible)
    Isolation Impedance: > 10 kΩ at bias frequency
    Off-state RF impedance: > 30 dB isolation at operating frequency


================================================================================
PREFERRED PCB LAYOUT (Critical for UHF/Microwave Bands)
================================================================================

    1. Keep all SMD components within 2-3 mm of each other
    2. Place RFC choke and bypass cap DIRECTLY at PIN diode cathode
    3. RF trace from element to RFC choke should be < 2 mm, wide (50 mil)
    4. Bias line to PIN cathode kept separate from RF line, routed orthogonal
    5. Ground plane on all layers: both sides of PCB
    6. For 20cm band (1296 MHz): consider microstrip bias choke instead of lumped
    7. No stubs or dangling traces - all traces terminated

    Recommended PCB substrate:
      - FR-4 for 70cm/33cm (acceptable loss)
      - RT/duroid 5880 for 20cm (lower loss tangent, better stability)
      - Trace width at 50Ω: ~30 mil on standard 1.6mm FR-4


================================================================================
MEASUREMENT NOTES
================================================================================

    Forward Bias Verification (using network analyzer):
    ─────────────────────────────────────────────────
    - Apply +12V to cathode via 1-2kΩ limit resistor
    - Measure S21 (transmission): should see < -0.5 dB loss
    - Measure S11 (reflection): should see < -15 dB return loss
    - Best insertion loss occurs at optimal bias current (~15 mA)


    Reverse Bias Verification:
    ──────────────────────────
    - Ground cathode (0V), or apply -5V bias for maximum isolation
    - Measure S21: should see < -30 dB isolation at operating frequency
    - Measure S11: should see > -10 dB return loss (element now looks like
      capacitive stub, ~0.6 pF to ground)
