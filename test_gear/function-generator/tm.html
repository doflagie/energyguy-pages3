CHAPTER 1 — GENERAL INFORMATION

1-1. SCOPE

This manual covers design, construction, and calibration of a function generator producing sine, square, and triangle waveforms from 1 Hz to 5 MHz. Applications include circuit testing, filter characterization, oscilloscope calibration, and modulation sources.

1-2. APPLICABLE DOCUMENTS

TM-TGEAR-002 (Audio Oscillator), TM-TGEAR-020 (Oscilloscope), TM-TGEAR-010 (Frequency Counter), TM-CAL-002 (GPS 1PPS).

WARNINGIf powered from AC mains, use an isolation transformer. Output ground and instrument ground share the same chassis potential. Connecting to another mains-connected instrument without isolation can create a shock hazard or ground loop that corrupts measurements.

CHAPTER 2 — THEORY OF OPERATION

2-1. XR-2206 OR DDS ARCHITECTURE

Classic function generators use the XR-2206 or ICL8038 monolithic ICs, which generate triangle waves internally, then use a sine shaper (piecewise-linear resistor network) to convert triangle to sine. Modern designs use a DDS chip (AD9833 or AD9850) for direct digital synthesis of all waveforms.

2-2. DDS WAVEFORM GENERATION

A DDS accumulator steps a phase register at each clock cycle. The output of a sine lookup table is converted to an analog voltage by a DAC. The frequency is:

DDS output frequencyfout = (M × fclk) / 2N [M = frequency tuning word, N = accumulator bits]

2-3. OUTPUT STAGE

A unity-gain buffer (op-amp, TL072 or AD8066) drives the output through a calibrated attenuator (step + continuous). DC offset is added via a summing amplifier for waveform positioning.

CHAPTER 4 — ASSEMBLY PROCEDURES

  1. Install DDS module on MCU SPI bus. Verify FSYNC, SCLK, SDATA connections.
  2. Apply 3.3 V to AD9833 VDD (regulated from on-board LDO). Verify DDS output on oscilloscope before MCU firmware.
  3. Write test code: set frequency word for 1 kHz sine. Verify 1 kHz on oscilloscope.
  4. Install output buffer and attenuator network. Set output amplitude to 1 Vpp ±5% at maximum setting.
  5. Verify square wave rise time <50 ns at 1 MHz by using oscilloscope 10× probe.

CHAPTER 5 — CALIBRATION PROCEDURE

5-1. FREQUENCY CALIBRATION

  1. Connect output to frequency counter (TM-TGEAR-010) with GPS-disciplined reference.
  2. Set frequency to 1.000000 MHz. Record actual frequency.
  3. Adjust clock crystal frequency correction in firmware to bring reading to 1.000000 ± 0.001 MHz (1 ppm).
  4. Verify at 100 Hz, 10 kHz, 100 kHz, 1 MHz, 5 MHz. Log all results.

5-2. AMPLITUDE CALIBRATION

  1. Set output to 1 Vpp on DMM AC range or oscilloscope.
  2. Adjust output attenuator pot or DAC reference until oscilloscope reads 1.00 Vpp ±2%.
  3. Verify amplitude flat ±0.5 dB from 100 Hz to 1 MHz.

CHAPTER 6 — TUNING AND ADJUSTMENT

DC offset is adjusted by the offset pot. Full offset range is typically ±5 V for a ±5 V supply op-amp stage. Duty cycle of square wave output is adjusted by a comparator threshold pot; 50% ±1% is achievable with stable comparator hysteresis.
