CHAPTER 1 — GENERAL INFORMATION

1-1. SCOPE

This manual covers design, construction, and calibration of an RF signal generator from 100 kHz to 150 MHz with calibrated output levels from −120 dBm to 0 dBm. Applications include receiver sensitivity testing, antenna analyzer input, and filter response measurement.

1-2. APPLICABLE DOCUMENTS

TM-TGEAR-010 (Frequency Counter), TM-CAL-001 (WWV), TM-CAL-002 (GPS 1PPS), TM-CAL-015 (Attenuator Pads).

WARNINGIf this signal generator is powered from AC mains, use an isolation transformer on the power supply. RF output ground connects to the instrument chassis. Connecting to a second AC-powered instrument without isolation can create ground loops affecting measurement accuracy or creating shock hazard.

CHAPTER 2 — THEORY OF OPERATION

2-1. DDS SYNTHESIS

A DDS chip (AD9850 or AD9833) generates a stable, phase-continuous output from DC to 40 MHz (AD9850) or 12.5 MHz (AD9833). Above these limits, a PLL multiplier extends coverage to 150 MHz.

DDS output frequencyfout = (FTW × fclk) / 232 [FTW = 32-bit frequency tuning word]

2-2. OUTPUT LEVEL CONTROL

A step attenuator (0, 10, 20, 30, 40, 50, 60 dB) plus a variable attenuator provides −120 to 0 dBm output range. The step attenuator is calibrated (TM-TGEAR-022). Total level accuracy: ±2 dB.

CHAPTER 4 — ASSEMBLY PROCEDURES

  1. Assemble DDS module on shielded PCB. Verify DDS output with frequency counter at several frequencies.
  2. Build output amplifier (MAR-6 MMIC or MGA-82563): gain 20 dB, NF <5 dB, P1dB >+12 dBm.
  3. Install step attenuator chain. Calibrate each pad per TM-TGEAR-022 before assembly.
  4. Install PE4302 digital attenuator. Program via SPI; verify each 0.5 dB step with TinySA.
  5. Power on. Sweep 1–30 MHz. Output level should be flat ±2 dB.

CHAPTER 5 — CALIBRATION PROCEDURE

5-1. FREQUENCY CALIBRATION

  1. Set generator to 10.000000 MHz. Connect to frequency counter (GPS-disciplined, TM-TGEAR-010).
  2. Measure actual frequency. Compute ppm error. Adjust DDS clock frequency constant in firmware.
  3. Cross-check against WWV 10 MHz reception with zero-beat method per TM-CAL-001.

5-2. OUTPUT LEVEL CALIBRATION

  1. Set attenuator to 0 dB (max output). Measure level with TinySA at 10 MHz. Record Pmax (dBm).
  2. Switch each step attenuator in. Verify each step reduces level by 10 ±0.5 dB.
  3. Calibrate PE4302 digital attenuator at 0, 10, 20, 30 dB settings. Record actual vs. nominal and create correction table.

CHAPTER 6 — TUNING AND ADJUSTMENT

Level flatness vs. frequency is improved by equalizing the amplifier chain. Place a low-pass filter at the DDS output (50 MHz cutoff 7th-order elliptic) to suppress DDS clock spurs. Add a 3 dB pad between DDS amp and attenuator chain to improve output match.
