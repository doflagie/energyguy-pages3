CHAPTER 1 — GENERAL INFORMATION

1-1. SCOPE

This manual covers design, construction, and calibration of a frequency counter from 1 Hz to 400 MHz using reciprocal counting techniques. A GPS 1PPS reference (TM-CAL-002) disciplines the timebase for <1 ppm accuracy. The counter is the primary instrument for calibrating oscillators, GDOs, and signal generators.

1-2. APPLICABLE DOCUMENTS

TM-CAL-001 (WWV), TM-CAL-002 (GPS 1PPS), TM-CAL-003 (GPSDO), TM-CAL-004 (FM Broadcast).

1-3. SAFETY

CAUTIONMaximum input level at the counter front-end is typically 5 Vpp. Inputs above this level will destroy the input comparator IC. Use an attenuator probe when measuring high-level signals.

CHAPTER 2 — THEORY OF OPERATION

2-1. DIRECT COUNTING

A precision timebase (TCXO or GPS-disciplined OCXO) divides to produce a gate signal of period Tgate. Pulses of the input signal are counted during Tgate. The frequency is:

Frequency from count and gate timef = N / Tgate

Resolution = 1 count, so minimum resolution = 1/Tgate. A 1-second gate gives 1 Hz resolution; a 10-second gate gives 0.1 Hz resolution.

2-2. RECIPROCAL COUNTING

Reciprocal counters measure the period T of each input cycle, then compute f = 1/T. This provides constant relative resolution across all frequencies. Typical resolution: 8–9 significant digits at any frequency.

2-3. GPS TIMEBASE DISCIPLINE

The GPS receiver's 1 PPS output represents 1.000000000 Hz (within 50 ns of UTC). By measuring the counter's reference oscillator against 1 PPS over a 100-second window, the oscillator frequency error is determined to <0.01 ppm and corrected in firmware.

CHAPTER 4 — ASSEMBLY PROCEDURES

  1. Assemble input conditioning: 50 Ω termination, BNC input, LMH6702 amplifier, 74AC04 prescaler.
  2. Connect STM32 TIM2 input capture to prescaler output.
  3. Connect GPS 1 PPS to STM32 external interrupt input (PA0).
  4. Flash firmware (open-source reciprocal counter firmware, e.g., Barbouri / K6JCA design).
  5. Verify TCXO output on oscilloscope: clean 10 MHz square wave, no ringing >10%.

CHAPTER 5 — CALIBRATION PROCEDURE

5-1. GPS TIMEBASE CALIBRATION

  1. Connect GPS antenna to NEO-M8N. Wait for 3D fix (LED indicator steady, or NMEA GPRMC shows "A").
  2. Enable GPS discipline in firmware. Unit displays "GPS OK" when 1 PPS is received.
  3. Accumulate 100 GPS edges: firmware computes TCXO correction factor. Typical correction: 0–5 ppm.
  4. Apply correction. Accuracy is now better than 0.1 ppm (GPS-limited).

5-2. INPUT SENSITIVITY CALIBRATION

  1. Apply 10 MHz signal from calibrated signal generator at −20 dBm. Counter must trigger and display 10.000000 MHz.
  2. Reduce input to −30 dBm. Counter should still trigger. −35 dBm is the minimum sensitivity specification.
  3. Test at 400 MHz: apply −10 dBm, counter must display correctly through prescaler.

5-3. TRIGGER LEVEL CHECK

Set trigger level to +0.5 V and verify count of asymmetric pulse train. Adjust comparator threshold resistor divider for center-of-threshold operation on sine inputs.

CHAPTER 6 — TUNING AND ADJUSTMENT

TCXO trim is performed in firmware: compare measured 1 PPS interval to ideal 10,000,000 counts. Fractional error is applied as a multiplicative correction. The trim is stored in non-volatile memory and survives power-off.
