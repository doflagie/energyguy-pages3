================================================================================
SCHEMATIC: DIRECT-COUNT FREQUENCY COUNTER — HF INPUT CHAIN
TM-FC-001  Rev A
ESP32 PCNT Hardware Counter, 0.1 MHz – 60 MHz direct
Reciprocal mode for <1 MHz high-resolution
================================================================================

OVERVIEW
--------
The direct-count section uses the ESP32's built-in hardware Pulse Counter
(PCNT) peripheral to count input pulses during a precise gate interval
generated by ESP32's hardware timer. The PCNT is a 16-bit signed counter;
overflow interrupts extend it to a 64-bit software accumulator.

Maximum reliable input frequency: 40 MHz (limited by ESP32 PCNT sampling).
For 40–600 MHz: use prescaler path (sch_prescaler.txt).
For high resolution at low frequencies: use reciprocal mode (firmware).

PCNT CHARACTERISTICS (ESP32)
------------------------------
  Counter width:     16-bit signed (−32768 to +32767)
  Max count rate:    ~40 MHz (APB clock gating)
  Overflow ISR:      Extends to 64-bit via software accumulator
  Input pins:        Any GPIO; GPIO34–39 preferred (input-only, no internal drivers)
  Gate timing:       esp_timer (64-bit, 1 μs resolution)
  Reference:         80 MHz APB clock, disciplined by TCXO/GPSDO

74LVC14A CHARACTERISTICS:
  Supply: 3.3V
  Max input frequency: typically 200 MHz (datasheet), reliable to 60 MHz
  Hysteresis: 0.8–1.2V (Vcc = 3.3V) — good noise immunity
  Input clamping diodes: protect against overvoltage to some extent
  Logic level: CMOS compatible with ESP32 3.3V inputs

NOTE: A single 74LVC14A (6-inverter package) serves both the direct
input buffer and as an inverter for the prescaler output. The unused
inverters are tied input→output (feedback) to reduce EMI.


INPUT LEVEL REQUIREMENTS
--------------------------
  Minimum Vin_pp for reliable counting: ~0.9V (74LVC14A hysteresis window)
  Maximum safe Vin: 3.6V (74LVC14A absolute max = Vcc + 0.5V = 3.8V)
  Input impedance: ~1 kΩ (74LVC14A input + bias network)

  For signals below 100 mVpp: use ERA-3SM preamplifier (see sch_input_protection.txt).
  For signals above 3Vpp: use input attenuator (see sch_input_protection.txt).


GATE TIME GENERATION
----------------------

  The gate time is controlled by ESP32's esp_timer (hardware timer):
    Gate durations: 100 ms, 1 s, 10 s, 100 s
    Accuracy: limited by timebase reference (see sch_timebase_gpsdo.txt)

  Gate timer ISR sets a flag; main loop reads PCNT and computes frequency:
    frequency = count_total / gate_time_seconds

  Gate time vs. resolution at maximum count rate (40 MHz):
    Gate 100 ms: frequency = count / 0.1 → 10 Hz resolution, 0-40 MHz range
    Gate 1 s:    frequency = count / 1.0 → 1 Hz resolution, 0-40 MHz range
    Gate 10 s:   frequency = count / 10.0 → 0.1 Hz resolution, 0-40 MHz range
    Gate 100 s:  frequency = count / 100.0 → 0.01 Hz resolution


PCNT OVERFLOW HANDLING
------------------------

  PCNT overflows at 32,767 counts. At 40 MHz input, overflow occurs
  every 32767 / 40,000,000 = 819 μs — too frequent for software ISR at speed.

  Solution: Set PCNT hardware H_limit to 30,000 counts.
  Overflow ISR fires every 30,000 counts and increments software accumulator.
  At 40 MHz: ISR fires every 750 μs → 1333 ISR calls/second. Manageable.

  Software 64-bit accumulator:
    volatile int64_t pcnt_accum = 0;    // incremented by 30000 in ISR
    volatile bool gate_open = false;

    ISR: pcnt_accum += 30000; pcnt_unit_clear(PCNT_UNIT_0);

    At gate close:
      int16_t remainder;
      pcnt_get_counter_value(PCNT_UNIT_0, &remainder);
      total = pcnt_accum + remainder;
      frequency = total / gate_time;

  NOTE: Gate must start and stop cleanly between PCNT overflow events
  for accurate results. The firmware synchronizes gate boundaries to
  input signal edges in reciprocal mode (see firmware/reciprocal_counter.h).

FREQUENCY CALCULATION
-----------------------

  Direct mode:
    f (Hz) = total_count × prescale_factor / gate_time_seconds

  Reciprocal mode (period measurement):
    period_s = timer_ticks / reference_frequency
    f (Hz) = N_cycles / period_s
    (where N_cycles = number of input cycles measured, typically 1–1000)

  Resolution comparison at 1 kHz input:

    Direct, 1s gate:   resolution = 1 Hz        → 0.1%  (1000 ppm)
    Direct, 10s gate:  resolution = 0.1 Hz       → 0.01% (100 ppm)
    Reciprocal, N=100: resolution ≈ f² / (N × f_ref)
                       = (1000)² / (100 × 10,000,000) = 0.001 Hz → 1 ppb!

  The reciprocal counter's resolution is:
    δf = f_input² / (N × f_reference)

  At 14.175 MHz with N=100 cycles and 10 MHz reference:
    δf = (14.175×10⁶)² / (100 × 10×10⁶) = 200.9×10¹² / 10⁹ = 200 Hz
  At 14.175 MHz with N=10000 cycles:
    δf = 2 Hz at HF — excellent for transmitter frequency verification
