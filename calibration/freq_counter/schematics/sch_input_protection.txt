SCHEMATIC: INPUT PROTECTION AND SIGNAL CONDITIONING
TM-FC-001  Rev A
SMA Input, BAT54S Protection, Pi Attenuator, ERA-3SM Preamp,
Level Comparator, Band-Select Low-Pass Filter
================================================================================

OVERVIEW
--------
The input chain protects the sensitive PCNT and prescaler inputs from
overload while providing sufficient signal conditioning for reliable counting
across the 0.1 MHz – 3 GHz range.

Chain (top to bottom):
  1.  SMA input connector (50Ω)
  2.  BAT54S dual Schottky clamp (ESD and overload protection)
  3.  Pi attenuator (0 / −10 / −20 / −30 dB, selectable)
  4.  Low-pass filter (band selection; 6 cutoff frequencies)
  5.  ERA-3SM preamplifier (optional; for weak signals)
  6.  LMV7219 comparator / limiting amplifier (sine → square wave)
  7.  74LVC14A Schmitt trigger (noise immunity, 3.3V output)
  8.  ESP32 PCNT input or prescaler input

INPUT SIGNAL LEVEL GUIDE
--------------------------

  Input Level    Condition               Recommended Setting
  -----------    ---------               -------------------
  < −40 dBm      Very weak signal        ERA-3SM IN, attenuator 0 dB
  −40 to −20 dBm Weak signal             ERA-3SM IN (optional), 0 dB
  −20 to 0 dBm   Normal signal           ERA-3SM bypass, 0 dB
  0 to +10 dBm   Strong signal           ERA-3SM bypass, −10 dB
  +10 to +20 dBm Very strong             ERA-3SM bypass, −20 dB
  > +20 dBm      Overload risk           ERA-3SM bypass, −30 dB

  WARNING: Input power above +20 dBm (100 mW) will damage the BAT54S
  protection diodes and possibly the 74LVC14A. The protection diodes
  handle brief transients but not sustained power. ALWAYS start with
  the maximum attenuator (−30 dB) for unknown signal levels.


INPUT IMPEDANCE SWITCH (optional)
------------------------------------

  Some signal sources have 50Ω output; others have Hi-Z (e.g., oscillators
  with CMOS outputs). A switch S4 can select input termination:

  S4 position 1 (50Ω):  50Ω resistor from SMA center pin to GND (default)
  S4 position 2 (HiZ):  Remove 50Ω; input is Hi-Z (R ~10 kΩ, C ~5 pF)
                         Better for CMOS square wave sources (avoids loading)
  S4 position 3 (75Ω):  75Ω for video/cable television source equipment


SIGNAL SENSITIVITY TABLE
--------------------------

  Band         Freq       Min signal for counting (no ERA-3SM)
  ----         ----       ------------------------------------
  160M         1.85 MHz   ~5 mVpp  (Schmitt hysteresis 0.9V / load gain)
  40M          7.15 MHz   ~5 mVpp
  20M         14.175 MHz  ~5 mVpp
  2M         144 MHz     ~5 mVpp (74LVC14A still adequate)
  70cm       432 MHz     ~15 mVpp (input capacitance limits sensitivity)
  23cm      1296 MHz     ~50 mVpp (prescaler path; ERA-3SM helps significantly)
  13cm      2400 MHz     ~100 mVpp (ERA-3SM essential; MB506 ÷64 mode)

  With ERA-3SM in circuit (+20 dB gain):
  All bands: threshold ≈ 0.1–0.5 mVpp (−50 to −60 dBm minimum)
